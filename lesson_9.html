Dictionary: key va value bilan ishlash

Backenddagi JSON, API response, foydalanuvchi profili va sozlamalarning asosiy tuzilmasi bo‘lgan Python lug‘atini chuqur o‘rganamiz.

Dars maqsadi

Dars yakunida siz dictionary yaratasiz, ma’lumot o‘qiysiz va yangilaysiz, metodlarini ishlatasiz, ichma-ich dict hamda boshqa data structurelar bilan ishlashni bilasiz. Key/value cheklovlarini ham tushunasiz.

1. Dictionary nima?

Dictionary (qisqacha dict) — ma’lumotni key: value juftligi ko‘rinishida saqlovchi tuzilma. Listda elementga index orqali, dictda esa kalit (key) orqali murojaat qilinadi.

dictionary = {"key": value, "key2": value2}
user = {
    "name": "Ali",
    "age": 21,
    "city": "Toshkent"
}

print(user)         # {'name': 'Ali', 'age': 21, 'city': 'Toshkent'}
print(type(user))   # <class 'dict'>
🪪

Hayotiy misol

Pasport: ism → Ali, tug‘ilgan yil → 2004, shahar → Toshkent.

🌐

Backend misoli

API response: {"status": 200, "data": [...]}.

Muhim: Python 3.7+ da dict elementlari kiritilgan tartibda saqlanadi. Lekin dictning asosiy vazifasi tartib emas, key bo‘yicha tez qidirishdir.

7. Dictionary bo‘ylab for sikli

Dict bo‘ylab oddiy for yurganda faqat keylar keladi.

user = {"name": "Ali", "age": 21, "role": "admin"}

for key in user:
    print(key)
# name, age, role

Key va value bilan ishlash

for key, value in user.items():
    print(f"{key}: {value}")
# name: Ali
# age: 21
# role: admin
for key in user.keys():
    print(key)

for value in user.values():
    print(value)

10. Dictionary comprehension

List comprehension kabi, yangi dictni qisqa usulda yaratish mumkin.

{key_ifoda: value_ifoda for element in kolleksiya if shart}
sonlar = [1, 2, 3, 4, 5]
kvadratlar = {son: son ** 2 for son in sonlar}
print(kvadratlar)
# {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}
users = ["ali", "lola", "umar"]
user_lengths = {user: len(user) for user in users}
print(user_lengths)
# {'ali': 3, 'lola': 4, 'umar': 4}
# Faqat juft sonlar
juft_kvadratlar = {son: son ** 2 for son in sonlar if son % 2 == 0}
print(juft_kvadratlar)  # {2: 4, 4: 16}
