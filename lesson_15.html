random moduli pseudo-random qiymatlar yaratadi. U testlar, o‘yinlar, demo data va tasodifiy tanlovlar uchun yaxshi; parol yoki token kabi xavfsizlik qiymatlari uchun emas.

4. random.seed() — takrorlanuvchi natija

Test yozishda bir xil tasodifiy natijani qayta olish kerak bo‘lishi mumkin. seed() generator boshlang‘ich holatini belgilaydi.

import random

random.seed(42)
print(random.randint(1, 100))
print(random.choice(["ali", "lola", "umar"]))
Xavfsizlik: random deterministik va xavfsizlik uchun yaroqsiz. Parol reset tokeni, API key yoki session token yaratishda secrets ishlating. Python random dokumentatsiyasi ham bu modul kriptografiya uchun emasligini ta’kidlaydi.

5. secrets — xavfsiz tokenlar

secrets standart kutubxonasi kriptografik jihatdan xavfsiz tasodifiy qiymatlar uchun yaratilgan.

import secrets

reset_token = secrets.token_urlsafe(32)
api_key = secrets.token_hex(16)
verification_code = secrets.randbelow(900000) + 100000

print(reset_token)
print(api_key)
print(verification_code)

6. time moduli

time past darajadagi vaqt funksiyalarini beradi: kutish, Unix timestamp va kod ishlash vaqtini o‘lchash. Sana-format uchun ko‘pincha datetime qulayroq.

FunksiyaVazifasiMisol

time.perf_counter()Aniq vaqt o‘lchashPerformance test
time.monotonic()Orqaga qaytmaydigan soatTimeout hisoblash

start = time.perf_counter()
result = sum(range(1_000_000))

Backend eslatmasi: oddiy sinxron API endpoint ichida time.sleep() ishlatmang — u server oqimini bloklaydi. Asinxron FastAPI kodida kerak bo‘lsa await asyncio.sleep() ishlatiladi.

7. uuid — noyob ID yaratish

uuid standart moduli global miqyosda noyob identifierlar yaratadi. Fayl nomi, public ID, task ID va tokenlarga mos keladi.

import uuid

user_id = uuid.uuid4()
print(user_id)
print(str(user_id))

file_name = f"upload_{uuid.uuid4()}.jpg"
print(file_name)
UUID vs database ID: database ichki primary key sifatida integer ham ishlatilishi mumkin. UUID esa public URL va tashqi tizimlarga ID berishda foydali, chunki uni ketma-ket taxmin qilish qiyinroq.

10. Faker bilan test data yaratish

from faker import Faker
import random

fake = Faker()

def create_fake_user(user_id: int) -> dict:
    return {
        "id": user_id,
        "name": fake.name(),
        "email": fake.unique.email(),
        "username": fake.user_name(),
        "is_active": random.choice([True, True, True, False]),
        "created_at": fake.iso8601()
    }

users = [create_fake_user(i) for i in range(1, 6)]
for user in users:
    print(user)
Faker methodNatija
fake.name()Soxta ism
fake.email()Soxta email
fake.unique.email()Takrorlanmas email yaratishga urinadi
fake.user_name()Username
fake.date_time()Sana-vaqt
fake.uuid4()UUID
fake.profile()Profil ma’lumotlari dicti
Xavfsizlik va maxfiylik: Faker ma’lumotini faqat demo/test muhiti uchun ishlating. Production foydalanuvchi ma’lumotlarini fake data bilan aralashtirmang va real shaxsiy ma’lumotni test muhitiga ko‘chirmang.

15. Mini loyiha: test foydalanuvchi generatori

from faker import Faker
from datetime import datetime, timezone
import secrets
import random

fake = Faker()

def create_demo_user(user_id: int) -> dict:
    return {
        "id": user_id,
        "username": fake.unique.user_name(),
        "email": fake.unique.email(),
        "role": random.choice(["user", "editor", "admin"]),
        "is_active": random.choice([True, True, True, False]),
        "api_token": secrets.token_urlsafe(16),
        "created_at": datetime.now(timezone.utc).isoformat()
    }

users = [create_demo_user(id) for id in range(1, 4)]
for user in users:
    print(user)
Production uchun: demo user tokenlarini real autentifikatsiya tokeni sifatida ishlatmang. Real tokenlar database’da xavfsiz boshqarilishi, expire bo‘lishi va kerak bo‘lsa hashlangan holda saqlanishi kerak.
Mustaqil mashq: 20 ta Faker user yarating. Faqat is_active=True bo‘lganlarini list comprehension bilan oling, so‘ng username bo‘yicha sorted(..., key=lambda ...) orqali saralang va JSON faylga saqlang.
