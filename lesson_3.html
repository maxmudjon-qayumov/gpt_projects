Python: Index va List

Bir nechta ma’lumotni bitta o‘zgaruvchida saqlash, ularni topish va boshqarishni o‘rganamiz.

Dars maqsadi

Dars oxirida siz index nima ekanini tushunasiz, list yaratasiz, elementlarga murojaat qilasiz va listning asosiy metodlaridan foydalana olasiz.

1. List nima?

List — bir nechta qiymatlarni bitta o‘zgaruvchida saqlaydigan ma’lumot turi. U kvadrat qavslar [ ] bilan yoziladi.

mevalar = ["olma", "banan", "anor", "uzum"]
print(mevalar)

List ichida matn, son va hatto boshqa listlar ham bo‘lishi mumkin.

🛒

Hayotiy misol

Xaridlar ro‘yxati: non, sut, tuxum, mevalar.

📚

Dasturdagi misol

O‘quvchilarning ismlari, test natijalari, mahsulot narxlari.

List o‘zgaruvchan: yaratilgandan so‘ng unga yangi element qo‘shish, o‘chirish yoki almashtirish mumkin.

2. Index nima?

Index — listdagi elementning tartib raqami. Python’da sanash 0 dan boshlanadi, 1 dan emas.

olmaindex: 0
bananindex: 1
anorindex: 2
uzumindex: 3
mevalar = ["olma", "banan", "anor", "uzum"]
print(mevalar[0])  # olma
print(mevalar[2])  # anor
Muhim: birinchi element mevalar[0] bo‘ladi. mevalar[1] esa ikkinchi element.

Manfiy index

List oxiridan boshlab olish uchun manfiy index ishlatiladi:

print(mevalar[-1])  # uzum — oxirgi element
print(mevalar[-2])  # anor

3. Elementni almashtirish

Index orqali list ichidagi element qiymatini o‘zgartirish mumkin.

ranglar = ["qizil", "ko‘k", "yashil"]
ranglar[1] = "sariq"
print(ranglar)

Natija: ["qizil", "sariq", "yashil"].

4. Listning asosiy metodlari

Metod — list bilan ishlash uchun tayyor buyruq. Metod list nomidan keyin nuqta qo‘yib yoziladi: mevalar.append(...).

MetodVazifasiMisol
append()Oxiriga bitta element qo‘shadimevalar.append("nok")
insert()Kerakli indexga element qo‘shadimevalar.insert(1, "shaftoli")
remove()Qiymati bo‘yicha elementni o‘chiradimevalar.remove("banan")
pop()Index bo‘yicha elementni o‘chiradimevalar.pop(0)
sort()Elementlarni tartiblaydimevalar.sort()
reverse()Listni teskari qiladimevalar.reverse()
count()Qiymat necha marta kelganini sanaydisonlar.count(5)
index()Qiymatning indexini topadimevalar.index("anor")
clear()List ichini tozalaydimevalar.clear()

5. Metodlar amalda

mevalar = ["olma", "banan", "anor"]
mevalar.append("uzum")
mevalar.insert(1, "nok")
mevalar.remove("banan")
print(mevalar)

Natija: ["olma", "nok", "anor", "uzum"].

sonlar = [8, 2, 5, 2, 10]
sonlar.sort()
print(sonlar)          # [2, 2, 5, 8, 10]
print(sonlar.count(2)) # 2

6. List uzunligi: len()

len() list ichidagi elementlar sonini qaytaradi.

fanlar = ["matematika", "ona tili", "informatika"]
print(len(fanlar))  # 3
Ko‘p uchraydigan xato: mavjud bo‘lmagan indexga murojaat qilish IndexError beradi. Masalan, 3 ta elementli listda fanlar[5] yozish xato.

7. Amaliy loyiha: xaridlar ro‘yxati

xaridlar = ["non", "sut", "tuxum"]
print("Boshlang‘ich ro‘yxat:", xaridlar)
xaridlar.append("shakar")
xaridlar.remove("sut")
print("Yangilangan ro‘yxat:", xaridlar)
print("Birinchi mahsulot:", xaridlar[0])
print("Mahsulotlar soni:", len(xaridlar))
Mustaqil mashq: 5 ta sevimli filmingizdan list yarating. Bittasini append() bilan qo‘shing, birini remove() bilan o‘chiring va listni sort() bilan tartiblang.
