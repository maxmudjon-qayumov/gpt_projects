Lambda funksiyalar va OOP oldi roadmap

Qisqa funksiyalarni to‘g‘ri joyda ishlatish, `if else` bilan qo‘llash va OOPdan avval mustahkamlash kerak bo‘lgan Python mavzularini o‘rganamiz.

Dars maqsadi

Dars yakunida siz lambda funksiyasi nima ekanini, qachon u qulay yoki noqulay bo‘lishini, uni sorted(), map(), filter() va if else bilan ishlatishni bilasiz. Oxirida OOPga tayyorgarlik rejasiga ega bo‘lasiz.

1. Lambda funksiya nima?

Lambda — qisqa, nomsiz va odatda bir qatorli funksiya. U oddiy def funksiyaning ixcham ko‘rinishi hisoblanadi.

lambda parametrlar: qaytariladigan_ifoda
# Oddiy funksiya
def qoshish(a, b):
    return a + b

# Xuddi shu ishni lambda bilan
qoshish_lambda = lambda a, b: a + b

print(qoshish(2, 3))        # 5
print(qoshish_lambda(2, 3)) # 5
Asosiy qoida: lambda tanasida faqat bitta ifoda bo‘ladi. U avtomatik ravishda shu ifoda natijasini qaytaradi; return yozilmaydi.

4. sorted() va lambda

sorted() elementlarni saralaydi. Murakkab obyektlarda qaysi qiymat bo‘yicha saralashni key=lambda ... orqali beramiz.

users = [
    {"name": "Ali", "age": 25},
    {"name": "Lola", "age": 19},
    {"name": "Umar", "age": 22}
]

by_age = sorted(users, key=lambda user: user["age"])
print(by_age)

Natijada foydalanuvchilar yosh bo‘yicha o‘sish tartibida: Lola (19), Umar (22), Ali (25).

products = [
    {"name": "Telefon", "price": 250},
    {"name": "Laptop", "price": 800},
    {"name": "Quloqchin", "price": 50}
]

expensive_first = sorted(products, key=lambda product: product["price"], reverse=True)
print(expensive_first)

reverse=True saralashni kamayish tartibida bajaradi.

5. map() va lambda

map() har bir elementga bitta funksiyani qo‘llaydi. Python 3 da natija map obyekt bo‘lgani uchun ko‘pincha list() bilan listga aylantiriladi.

sonlar = [1, 2, 3, 4]
kvadratlar = list(map(lambda son: son ** 2, sonlar))
print(kvadratlar)  # [1, 4, 9, 16]
names = ["ali", "lola", "umar"]
formatted = list(map(lambda name: name.title(), names))
print(formatted)  # ['Ali', 'Lola', 'Umar']
Qaysi biri yaxshi? Oddiy list yaratishda comprehension ko‘pincha o‘qishga osonroq: [son ** 2 for son in sonlar]. `map()` esa mavjud funksiyani qo‘llash yoki pipeline holatlarida qulay.

6. filter() va lambda

filter() sharti True bergan elementlarni qoldiradi.

sonlar = [1, 2, 3, 4, 5, 6]
juft_sonlar = list(filter(lambda son: son % 2 == 0, sonlar))
print(juft_sonlar)  # [2, 4, 6]
users = [
    {"name": "Ali", "active": True},
    {"name": "Lola", "active": False},
    {"name": "Umar", "active": True}
]

active_users = list(filter(lambda user: user["active"], users))
print(active_users)

Bu kod faqat active=True bo‘lgan foydalanuvchilarni qaytaradi.

O‘qilishi oson variant: ko‘pincha [user for user in users if user["active"]] ko‘rinishidagi list comprehension tavsiya etiladi.

7. Lambda ichida if else

Lambda bitta ifoda qabul qiladi. Shuning uchun shartli natija ternary expression yordamida yoziladi:

lambda x: true_holat if shart else false_holat
juft_yoki_toq = lambda son: "juft" if son % 2 == 0 else "toq"

print(juft_yoki_toq(8))  # juft
print(juft_yoki_toq(7))  # toq
get_discount = lambda is_vip: 15 if is_vip else 5

print(get_discount(True))   # 15
print(get_discount(False))  # 5

Lambda ichida oddiy ko‘p qatorli if yozib bo‘lmaydi: lambda x: if x > 0: ... — sintaksis xatosi. Murakkab shart uchun def ishlating.

8. Lambda bilan if/else amaliy misollar

# Har bir bahoga holat berish
baholar = [95, 72, 48, 89]
holatlar = list(map(lambda baho: "o‘tdi" if baho >= 60 else "yiqildi", baholar))
print(holatlar)
# ['o‘tdi', 'o‘tdi', 'yiqildi', 'o‘tdi']

# API foydalanuvchisi uchun rol chiqarish
role_label = lambda role: "Administrator" if role == "admin" else "Foydalanuvchi"
print(role_label("admin"))  # Administrator

List comprehension bilan taqqoslash

baholar = [95, 72, 48, 89]

# Lambda + map
holat_1 = list(map(lambda b: "o‘tdi" if b >= 60 else "yiqildi", baholar))

# List comprehension — ko‘pincha qulayroq
holat_2 = ["o‘tdi" if b >= 60 else "yiqildi" for b in baholar]

10. Backend misoli: API ma’lumotini tayyorlash

products = [
    {"name": "Laptop", "price": 800, "in_stock": True},
    {"name": "Mouse", "price": 25, "in_stock": False},
    {"name": "Keyboard", "price": 60, "in_stock": True}
]

# Faqat ombordagi mahsulotlar
in_stock = list(filter(lambda p: p["in_stock"], products))

# API uchun qisqa response
response = list(map(lambda p: {
    "name": p["name"],
    "price": p["price"],
    "label": "Premium" if p["price"] >= 500 else "Standard"
}, in_stock))

# Narx bo‘yicha saralash
response = sorted(response, key=lambda item: item["price"], reverse=True)
print(response)

Haqiqiy katta backend loyihada bunday mantiqni alohida nomli serializer/service funksiyasiga o‘tkazish ma’qul. Lambda bu yerda faqat mavzuni ko‘rsatish uchun ishlatildi.

11. OOPga o‘tishdan avval nimalarni bilish kerak?

OOP (Object-Oriented Programming) ni boshlashdan oldin quyidagi mavzularni amalda yozib ko‘rish muhim. Bu bilimlar OOPdagi class, object, method va inheritance ni tez tushunishga yordam beradi.

Funksiyalarni mustahkamlash. Parametrlar, return, scope, default parametr, *args, **kwargs. OOPdagi method — aslida class ichidagi funksiya.
Data structurelar. List, tuple, set, dict; ular ichida aylanish, qo‘shish/o‘chirish, nested tuzilmalar va comprehensionlar.
Shart va sikllar. if/elif/else, nested if, for, while, break, continue.
Exception handling. try, except, else, finally, raise. Xatolarni boshqarish backend uchun juda muhim.
Modullar va import. Kodni bir nechta .py faylga ajratish, import, from ... import ..., paketlar va __name__ == "__main__".
Fayllar va JSON. with open(...), o‘qish/yozish, json.loads(), json.dumps(). API aynan JSON bilan ishlaydi.
Virtual environment va pip. venv, kutubxona o‘rnatish, requirements.txt. Django/FastAPI loyihasi uchun shart.
Type hints va code style. list[str], dict[str, int], docstring, PEP 8. Bu kod sifatini oshiradi.

13. Mustaqil loyiha

users = [
    {"username": "ali", "orders": 5, "active": True},
    {"username": "lola", "orders": 0, "active": False},
    {"username": "umar", "orders": 12, "active": True}
]

# 1. Faqat faol userlarni ajrating
active_users = list(filter(lambda user: user["active"], users))

# 2. Har userga daraja bering
levels = list(map(lambda user: {
    "username": user["username"],
    "level": "VIP" if user["orders"] >= 10 else "Oddiy"
}, active_users))

# 3. Buyurtmalar soni bo‘yicha saralang
result = sorted(levels, key=lambda item: item["username"])
print(result)
Qo‘shimcha mashq: Shu loyihani lambda ishlatmasdan, alohida def is_active(user) va def get_level(user) funksiyalari bilan yozing. Qaysi variant o‘qishga qulayroq ekanini solishtiring.
