Exception handling: xatolarni boshqarish

Dastur xato sababli to‘xtab qolmasligi uchun `try`, `except`, `else`, `finally` va `raise` dan xavfsiz foydalanishni o‘rganamiz.

Dars maqsadi

Dars oxirida siz exception nima ekanini, keng tarqalgan xato turlarini, try/except/else/finally bloklarini, custom exception va raise ni backend misollarida ishlata olasiz.

1. Exception nima?

Exception — dastur ishlayotgan vaqtda yuz beradigan kutilmagan xato. Agar u ushlanmasa, dastur to‘xtab qoladi.

yosh = int(input("Yoshingiz: "))
print(yosh + 1)

Foydalanuvchi abc yozsa, ValueError chiqadi. Dastur to‘xtaydi. Exception handling shu holatni nazorat qilishga yordam beradi.

🛡️

Foydalanuvchi xatosi

Noto‘g‘ri format, bo‘sh maydon, mavjud bo‘lmagan ID.

🌐

Tashqi tizim xatosi

API javob bermadi, internet uzildi, fayl topilmadi.

🗄️

Backend xatosi

Database ulanishi, noto‘g‘ri JSON, noto‘g‘ri key.

🧹

Tozalash

Fayl yoki database ulanishini har holatda yopish.

4. Bir nechta exception

try:
    son = int(input("Son kiriting: "))
    natija = 100 / son
    print(natija)
except ValueError:
    print("Sonni to‘g‘ri formatda kiriting.")
except ZeroDivisionError:
    print("0 ga bo‘lish mumkin emas.")

Bir xil ish bajarilsa, exceptionlarni tuple qilib yozish mumkin:

try:
    value = int(input("Son: "))
except (ValueError, TypeError):
    print("Noto‘g‘ri son kiritildi.")
except Exception: ehtiyotkorlik bilan: u deyarli barcha xatoni ushlaydi va haqiqiy dastur xatosini yashirishi mumkin. Uni faqat log yozish yoki tashqi chegaradagi umumiy fallback uchun ishlating.

5. Exception obyektini olish

as e orqali xato matnini olish mumkin. Bu ayniqsa log yozishda foydali.

try:
    result = 10 / 0
except ZeroDivisionError as error:
    print(f"Hisoblash xatosi: {error}")
# Hisoblash xatosi: division by zero

Production backendda foydalanuvchiga texnik xato tafsilotini yubormang; uni server logiga yozing, foydalanuvchiga umumiy xabar bering.

finally xato bo‘lsa ham, bo‘lmasa ham ishlaydi.

7. raise — xatoni o‘zimiz chiqarish

raise bilan biznes qoidasi buzilganda o‘z exceptionimizni chiqaramiz.

def calculate_age(birth_year):
    if birth_year > 2026:
        raise ValueError("Tug‘ilgan yil kelajakda bo‘lishi mumkin emas.")
    return 2026 - birth_year

try:
    print(calculate_age(2030))
except ValueError as error:
    print(error)

Natija: Tug‘ilgan yil kelajakda bo‘lishi mumkin emas.

Custom exception

class InvalidPasswordError(Exception):
    pass

def validate_password(password):
    if len(password) < 8:
        raise InvalidPasswordError("Parol kamida 8 belgidan iborat bo‘lsin.")
    return True
Custom exception katta backend loyihada xatolarni turlarga ajratish va API statuslarni boshqarish uchun foydali.

9. Fayl va API bilan xatolar

# Fayl xatosini ushlash
try:
    with open("config.json", "r", encoding="utf-8") as file:
        content = file.read()
except FileNotFoundError:
    print("config.json fayli topilmadi.")
except PermissionError:
    print("Faylni o‘qish uchun ruxsat yo‘q.")
# requests kutubxonasi bilan API misoli
import requests

try:
    response = requests.get("https://api.example.com/users", timeout=5)
    response.raise_for_status()
    data = response.json()
except requests.Timeout:
    print("Server juda uzoq javob berdi.")
except requests.RequestException:
    print("API bilan bog‘lanishda xato.")
Backend qoidasi: tarmoq so‘roviga doim timeout bering. Aks holda server javobini cheksiz kutib qolishi mumkin.

10. Logging — xatoni foydalanuvchiga emas, logga yozish

import logging

logging.basicConfig(level=logging.INFO)

try:
    result = 10 / 0
except ZeroDivisionError:
    logging.exception("Hisoblashda kutilmagan xato")
    print("Server xatosi yuz berdi. Keyinroq urinib ko‘ring.")

logging.exception() xato haqida to‘liq traceback ni logga yozadi. Bu developer uchun muhim, foydalanuvchi uchun esa xavfsizroq.

12. Amaliy loyiha: xavfsiz JSON foydalanuvchi o‘qish

import json

def load_user(filename: str) -> dict | None:
    try:
        with open(filename, "r", encoding="utf-8") as file:
            user = json.load(file)
    except FileNotFoundError:
        print("Foydalanuvchi fayli topilmadi.")
        return None
    except json.JSONDecodeError:
        print("JSON fayl formati buzilgan.")
        return None
    else:
        if not user.get("email"):
            print("Email topilmadi.")
            return None
        return user
    finally:
        print("Fayl tekshiruvi tugadi.")

current_user = load_user("user.json")
if current_user:
    print(f"Xush kelibsiz, {current_user['name']}!")
Mustaqil mashq: foydalanuvchidan ikki son oling. Noto‘g‘ri qiymat, nolga bo‘lish va manfiy son holatlarini alohida exception yoki raise bilan boshqaring.
