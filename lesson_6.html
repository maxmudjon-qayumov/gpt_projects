Shart operatorlari: if, elif, else

Dasturga qaror qabul qilishni o‘rgatamiz: foydalanuvchi kim, ruxsat bormi, ma’lumot to‘g‘rimi — barchasi shartlar orqali tekshiriladi.

Dars maqsadi

Dars yakunida siz if, elif, else sintaksisini yozasiz, ichma-ich shartlarni tushunasiz hamda ularni backenddagi autentifikatsiya, ruxsat va validatsiya misollarida qo‘llaysiz.

1. Shart operatori nima?

Shart operatori dasturga qaror qabul qilish imkonini beradi. U savol beradi: “Bu shart rostmi?” Agar javob True bo‘lsa bir kod, False bo‘lsa boshqa kod bajariladi.

Shart→True yoki False→Mos kod bajariladi
✅

if

Shart rost bo‘lsa ishlaydi.

↔️

elif

Oldingi shart noto‘g‘ri bo‘lsa, yangi shartni tekshiradi.

🔁

else

Hech qaysi shart rost bo‘lmasa ishlaydi.

🧱

Indentatsiya

Ichkaridagi kod 4 ta bo‘sh joy bilan suriladi.

2. if sintaksisi

if shart:
    bajariladigan_kod

Ikki muhim qoida: shart satrining oxirida : bo‘ladi, undan keyingi kod esa 4 ta bo‘sh joy bilan ichkariga suriladi.

yosh = 18

if yosh >= 18:
    print("Siz voyaga yetgansiz.")

Natija: Siz voyaga yetgansiz., chunki 18 >= 18 — True.

yosh = 15

if yosh >= 18:
    print("Siz voyaga yetgansiz.")

print("Dastur tugadi.")

Natija faqat Dastur tugadi.. Sababi shart False; if ichidagi qator o‘tkazib yuboriladi.

3. if ... else

Ikki xil holat bo‘lsa, else ishlatiladi. else ning o‘zida shart bo‘lmaydi.

yosh = 16

if yosh >= 18:
    print("Kirishga ruxsat berildi.")
else:
    print("Kirish uchun yosh yetarli emas.")

Natija: Kirish uchun yosh yetarli emas..

Qoidasi: else faqat bitta if zanjirining oxirida yoziladi. Bir zanjirda bir nechta else bo‘lishi mumkin emas.

4. if ... elif ... else

Uch yoki undan ortiq variantni tekshirish uchun elif ishlatiladi. Python yuqoridan pastga tekshiradi va birinchi rost shartdan keyin to‘xtaydi.

baho = 82

if baho >= 90:
    print("A'lo — 5 baho")
elif baho >= 70:
    print("Yaxshi — 4 baho")
elif baho >= 60:
    print("Qoniqarli — 3 baho")
else:
    print("Qoniqarsiz — qayta topshirish kerak")

Natija: Yaxshi — 4 baho. 82 >= 90 noto‘g‘ri, 82 >= 70 esa rost.

6. Ichma-ich if (nested if)

Ichma-ich if — bir if ichida yana bir if yozish. U ikkinchi tekshiruv faqat birinchi shart rost bo‘lganda kerak bo‘lsa ishlatiladi.

yosh = 20
hujjat_bor = True

if yosh >= 18:
    print("Yosh talabi bajarildi.")
    if hujjat_bor:
        print("Kirishga ruxsat berildi.")
    else:
        print("Hujjat kerak.")
else:
    print("Yosh yetarli emas.")

Natija:

Yosh talabi bajarildi.
Kirishga ruxsat berildi.
Qanday ishlaydi?
1. Avval yosh >= 18 tekshiriladi.
2. Rost bo‘lgani uchun ichkaridagi kodga kiradi.
3. Keyin hujjat_bor tekshiriladi.
4. U ham rost bo‘lgani uchun ruxsat beriladi.
