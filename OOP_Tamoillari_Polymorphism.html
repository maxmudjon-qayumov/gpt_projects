Polymorphism — bir interfeys, turli xatti-harakat

Bir xil method nomi orqali turli objectlar o‘ziga mos harakatni bajarishini o‘rganamiz.

Dars maqsadi

Polymorphism nima ekanini, method overriding, duck typing, built-in polymorphism va backenddagi payment/notification misollarini tushunasiz.

1. Polymorphism nima?

Polymorphism — “ko‘p shakllilik”. Bir xil interfeys yoki method nomi turli objectlarda turlicha natija berishi mumkin.

Hayotiy misol

“Ovoz chiqar” buyrug‘i: Cat → miyov, Dog → vovullash.

Backend misoli

send(message): EmailNotification email yuboradi, SMSNotification SMS yuboradi.

Foydasi: kod objectning aniq turini tekshirmasdan umumiy method orqali ishlashi mumkin. Yangi tur qo‘shish osonlashadi.

2. Method overriding orqali polymorphism

class Animal:
    def sound(self):
        return "Noma’lum ovoz"

class Cat(Animal):
    def sound(self):
        return "Miyov"

class Dog(Animal):
    def sound(self):
        return "Vov"

animals = [Cat(), Dog(), Animal()]
for animal in animals:
    print(animal.sound())
# Miyov
# Vov
# Noma’lum ovoz

Sikl har bir objectda bir xil sound() ni chaqirdi, ammo object turiga qarab turli natija chiqdi.

Har yangi payment turi uchun eski kodni o‘zgartirish kerak bo‘ladi. Polymorphismda esa yangi class qo‘shiladi:

class Payment:
    def pay(self, amount):
        raise NotImplementedError

class CardPayment(Payment):
    def pay(self, amount):
        return f"Karta orqali {amount} so‘m to‘landi"

class CashPayment(Payment):
    def pay(self, amount):
        return f"Naqd {amount} so‘m qabul qilindi"

def checkout(payment, amount):
    return payment.pay(amount)

print(checkout(CardPayment(), 100000))
print(checkout(CashPayment(), 100000))

4. Duck typing

Python’da polymorphism inheritance talab qilmaydi. Duck typing qoidasi: objectda kerakli method bo‘lsa, uning aniq classi muhim emas. “Agar o‘rdakka o‘xshab yurib, o‘rdakka o‘xshab ovoz chiqarsa — o‘rdak.”

class EmailSender:
    def send(self, message):
        return f"Email: {message}"

class TelegramSender:
    def send(self, message):
        return f"Telegram: {message}"

def notify(sender, message):
    return sender.send(message)

print(notify(EmailSender(), "Buyurtma qabul qilindi"))
print(notify(TelegramSender(), "Buyurtma qabul qilindi"))

Bu classlar bir parentdan meros olmasa ham, ikkalasida send() borligi uchun notify() bilan ishlaydi.

Ehtiyot bo‘ling: duck typing juda moslashuvchan, lekin method nomi yoki parametrlari bir xil bo‘lmasa runtime xato chiqadi. Katta loyihada abstract class yoki Protocol bilan contractni aniq belgilang.

6. Operator overloading

Class ichida maxsus (dunder) methodlar orqali operatorlarning object uchun ma’nosini berish mumkin.

class Money:
    def __init__(self, amount):
        self.amount = amount

    def __add__(self, other):
        return Money(self.amount + other.amount)

    def __str__(self):
        return f"{self.amount} so‘m"

a = Money(5000)
b = Money(3000)
print(a + b)  # 8000 so‘m

7. Polymorphism va inheritance

Inheritance polymorphismga yordam beradi, lekin u shart emas. Parent class umumiy interface beradi, childlar esa methodni override qiladi.

class Report:
    def export(self):
        raise NotImplementedError

class PDFReport(Report):
    def export(self):
        return "PDF fayl yaratildi"

class CSVReport(Report):
    def export(self):
        return "CSV fayl yaratildi"

def export_report(report):
    print(report.export())

export_report(PDFReport())
export_report(CSVReport())
Open/Closed Principle: export_report() kodini o‘zgartirmasdan ExcelReport qo‘shish mumkin. Bu yaxshi OOP dizayn belgisi.

8. Backend amaliy loyiha: notification service

class Notification:
    def send(self, recipient, message):
        raise NotImplementedError

class EmailNotification(Notification):
    def send(self, recipient, message):
        return f"Email → {recipient}: {message}"

class SMSNotification(Notification):
    def send(self, recipient, message):
        return f"SMS → {recipient}: {message}"

class TelegramNotification(Notification):
    def send(self, recipient, message):
        return f"Telegram → {recipient}: {message}"

def send_order_status(channel, user, status):
    return channel.send(user, f"Buyurtma holati: {status}")

channels = [EmailNotification(), SMSNotification(), TelegramNotification()]
for channel in channels:
    print(send_order_status(channel, "ali", "qabul qilindi"))

Yangi WhatsAppNotification qo‘shish uchun faqat yangi class yoziladi; mavjud send_order_status() o‘zgarmaydi.
