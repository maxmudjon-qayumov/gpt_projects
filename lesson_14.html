3. with open() — tavsiya etilgan usul

with bloki tugaganda fayl avtomatik yopiladi. Shu sababli har doim deyarli with open() ishlating.

# Faylga yozish
with open("notes.txt", "w", encoding="utf-8") as file:
    file.write("Salom, Python!\n")
    file.write("Bu ikkinchi qator.")

# Faylni o‘qish
with open("notes.txt", "r", encoding="utf-8") as file:
    content = file.read()

print(content)

encoding="utf-8" o‘zbekcha belgilarni to‘g‘ri saqlash uchun muhim.

7. json.dumps() va json.loads()

dumps — Python obyektini JSON stringga, loads — JSON stringni Python obyektiga aylantiradi.

import json

user = {"id": 1, "name": "Ali", "active": True}
json_text = json.dumps(user, ensure_ascii=False, indent=2)
print(json_text)

data = json.loads(json_text)
print(data["name"])  # Ali

8. JSON faylga yozish va o‘qish

import json

users = [
    {"id": 1, "name": "Ali", "active": True},
    {"id": 2, "name": "Lola", "active": False}
]

# JSON faylga yozish
with open("users.json", "w", encoding="utf-8") as file:
    json.dump(users, file, ensure_ascii=False, indent=2)

# JSON fayldan o‘qish
with open("users.json", "r", encoding="utf-8") as file:
    loaded_users = json.load(file)

print(loaded_users[0]["name"])  # Ali
ensure_ascii=False: o‘zbekcha harflar JSON faylida o‘qiladigan holatda saqlanadi. indent=2 faylni chiroyli formatlaydi.

9. JSON va exception handling

import json

def load_config(filename):
    try:
        with open(filename, "r", encoding="utf-8") as file:
            return json.load(file)
    except FileNotFoundError:
        print("Config fayli topilmadi.")
        return {}
    except json.JSONDecodeError:
        print("Config JSON formati buzilgan.")
        return {}

config = load_config("config.json")
port = config.get("port", 8000)
print(port)

13. Timezone — backend uchun muhim qoida

Serverlar va foydalanuvchilar turli vaqt zonalarida bo‘lishi mumkin. Backendda vaqtni odatda UTC da saqlash, foydalanuvchiga ko‘rsatishda lokal vaqtga o‘tkazish tavsiya etiladi.

from datetime import datetime, timezone

utc_now = datetime.now(timezone.utc)
print(utc_now)
Eslatma: datetime.now() timezone ma’lumoti bo‘lmagan (naive) vaqt yaratadi. Production backendda timezone-aware datetime bilan ishlash xavfsizroq.

14. Amaliy loyiha: JSON foydalanuvchi ombori

import json
from datetime import datetime, timezone
from pathlib import Path

FILE = Path("users.json")

def load_users():
    if not FILE.exists():
        return []
    with FILE.open("r", encoding="utf-8") as file:
        return json.load(file)

def save_users(users):
    with FILE.open("w", encoding="utf-8") as file:
        json.dump(users, file, ensure_ascii=False, indent=2)

def add_user(name, email):
    users = load_users()
    user = {
        "id": len(users) + 1,
        "name": name,
        "email": email,
        "created_at": datetime.now(timezone.utc).isoformat()
    }
    users.append(user)
    save_users(users)
    return user

print(add_user("Ali", "ali@mail.com"))

Bu mini loyiha JSON faylni kichik database kabi ishlatadi. Katta production tizimlarda PostgreSQL yoki boshqa haqiqiy database ishlatiladi.

Mustaqil mashq: foydalanuvchini email bo‘yicha qidiruvchi find_user(email) funksiyasini qo‘shing. Keyin user topilmasa None qaytarsin, topilsa uning ma’lumotini chiqarsin.
