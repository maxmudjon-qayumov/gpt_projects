Abstraction — murakkablikni yashirish

Object ichki ishlashini yashirib, foydalanuvchi uchun faqat kerakli interface qoldirish va abstract class yaratishni o‘rganamiz.

Dars maqsadi

Abstraction nima, abstract class va abstract methodlar nima uchun kerakligi, Pythonning abc moduli hamda backend service contractlarini tushunasiz.

1. Abstraction nima?

Abstraction — murakkab ichki jarayonni yashirib, foydalanish uchun zarur bo‘lgan oddiy interfeysni ko‘rsatish tamoyili.

Hayotiy misol

Avtomobilni yurgizish uchun tugmani bosasiz; ichki dvigatel qanday ishlashini bilishingiz shart emas.

Backend misoli

payment.pay() chaqiriladi; karta API, signatura va request detallarini service yashiradi.

Encapsulationdan farqi: encapsulation data va uning o‘zgarishini himoya qiladi; abstraction esa murakkab implementationni yashirib, “nima qilish mumkin” degan interfeysni beradi.

2. Abstract class nima?

Abstract class — object yaratish uchun emas, boshqa classlar uchun umumiy andoza/interface bo‘lib xizmat qiladigan class. Python’da bu uchun standart abc moduli ishlatiladi.

from abc import ABC, abstractmethod

class Payment(ABC):
    @abstractmethod
    def pay(self, amount):
        pass

# payment = Payment() → TypeError
QismMa’nosi
ABCAbstract Base Class.
@abstractmethodChild class yozishi shart bo‘lgan method.
Payment()Abstract method to‘ldirilmaguncha object yaratilmaydi.

3. Abstract methodni implement qilish

from abc import ABC, abstractmethod

class Payment(ABC):
    @abstractmethod
    def pay(self, amount):
        pass

class CardPayment(Payment):
    def pay(self, amount):
        return f"Karta orqali {amount} so‘m to‘landi"

class CashPayment(Payment):
    def pay(self, amount):
        return f"Naqd {amount} so‘m qabul qilindi"

print(CardPayment().pay(100000))
print(CashPayment().pay(100000))

CardPayment va CashPayment pay() methodini yozgani uchun object yaratiladi. Agar yozmasa, Python TypeError beradi.

Yangi provider qo‘shish murakkab.Abstract contract asosida yangi child class yaratiladi.

5. Abstract classda oddiy method ham bo‘lishi mumkin

Abstract classda faqat abstract method emas, umumiy tayyor method ham yozish mumkin.

from abc import ABC, abstractmethod

class Notification(ABC):
    def validate_message(self, message):
        if not message.strip():
            raise ValueError("Xabar bo‘sh bo‘lmasin")

    @abstractmethod
    def send(self, recipient, message):
        pass

class EmailNotification(Notification):
    def send(self, recipient, message):
        self.validate_message(message)
        return f"Email → {recipient}: {message}"

Validation bir marta parentda yozildi, barcha child class undan foydalanishi mumkin.

6. Abstraction va polymorphism

Bu ikki tamoyil ko‘pincha birga ishlaydi:

AbstractionPolymorphism
Qanday method bo‘lishini belgilaydi: pay().Har child bu methodni turlicha bajaradi.
Contract/interface yaratadi.Bir interfeysda turli behavior beradi.
Payment(ABC)CardPayment.pay(), CashPayment.pay()
Qisqa formula: abstraction — “nima qilish kerak?”, polymorphism — “har tur buni qanday bajaradi?”.

7. Interfacega bog‘lanish

def process_payment(payment: Payment, amount: int):
    return payment.pay(amount)

print(process_payment(CardPayment(), 50000))
print(process_payment(CashPayment(), 50000))

process_payment() Card yoki Cash implementation detallarini bilmaydi; faqat Payment contractini kutadi. Bu kodni test qilish va kengaytirishni osonlashtiradi.

8. Abstraction without ABC

Python’da duck typing sababli ABCsiz ham umumiy interface ishlatish mumkin. Lekin ABC aniq contract va xatoni erta ushlash uchun foydali.

# ABCsiz — ishlaydi, ammo method unutilsa runtime xato
class Printer:
    def print_document(self, text):
        return text

def print_file(printer, text):
    return printer.print_document(text)
Qachon ABC? Bir nechta implementation bo‘lsa, plugin/provider tizimi bo‘lsa yoki barcha child classlar ma’lum methodni yozishi shart bo‘lsa ABC ishlating.

9. Backend amaliy loyiha: storage service

from abc import ABC, abstractmethod

class Storage(ABC):
    @abstractmethod
    def save(self, filename, content):
        pass

    @abstractmethod
    def get_url(self, filename):
        pass

class LocalStorage(Storage):
    def save(self, filename, content):
        return f"Local diskka saqlandi: {filename}"

    def get_url(self, filename):
        return f"/media/{filename}"

class CloudStorage(Storage):
    def save(self, filename, content):
        return f"Cloud storagega saqlandi: {filename}"

    def get_url(self, filename):
        return f"https://cdn.example.com/{filename}"

def upload_file(storage: Storage, filename, content):
    storage.save(filename, content)
    return storage.get_url(filename)

print(upload_file(LocalStorage(), "photo.jpg", b"data"))
print(upload_file(CloudStorage(), "photo.jpg", b"data"))

Keyinchalik S3, Google Cloud Storage yoki boshqa provider qo‘shilsa Storage contractiga mos yangi class yoziladi.
