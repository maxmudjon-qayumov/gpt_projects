Python: String (matn) bilan ishlash

Matn yaratish, kesib olish, formatlash va uning kuchli metodlaridan foydalanishni o‘rganamiz.

Dars maqsadi

Dars yakunida siz Python’da string yaratishingiz, index va slicing ishlatishingiz, matnni formatlashingiz hamda asosiy string metodlarini qo‘llay olasiz.

1. String nima?

String — bu matnli ma’lumot turi. Python’da matn qo‘shtirnoq yoki apostrof ichida yoziladi. String turi str deb ataladi.

ism = "Aziza"
shahar = 'Samarqand'
xabar = "Bugun Python o‘rganamiz!"
print(type(ism))  # <class 'str'>
String o‘zgarmas (immutable): string ichidagi bitta belgini bevosita almashtirib bo‘lmaydi. Yangi string yaratish kerak.

2. String yozish turlari

" "

Bir qatorli string

Qo‘shtirnoq: "Salom" yoki apostrof: 'Salom'.

'''

Ko‘p qatorli string

Uchta qo‘shtirnoq bilan bir nechta qator yoziladi: '''Matn'''.

🔢

Raqam ham matn bo‘lishi mumkin

"2026" — string, 2026 esa int.

➕

String birlashtirish

"Salom" + " " + "dunyo" natijasi: "Salom dunyo".

bio = """Mening ismim Dilshod.
Men Python dasturlash tilini o‘rganmoqdaman.
Bu mening birinchi ko‘p qatorli matnim."""
print(bio)

3. Escape belgilar

Ba’zan string ichiga yangi qator, tab yoki qo‘shtirnoq yozish kerak bo‘ladi. Buning uchun escape belgilar qo‘llanadi.

BelgiVazifasiMisol
\nYangi qatorga o‘tkazadi"Salom\nDunyo"
\tTab (bo‘sh joy) qo‘shadi"Ism:\tAli"
\"String ichida qo‘shtirnoq"U \"Salom\" dedi"
\\Teskari chiziq yozadi"C:\\Users\\Ali"

4. Index va slicing

String ham belgilar ketma-ketligidir. Shu sababli list kabi index bilan bitta belgi, slicing bilan esa bir qism olinadi.

soz = "Python"
print(soz[0])    # P
print(soz[-1])   # n
print(soz[0:3])  # Pyt
print(soz[2:])   # thon
print(soz[:4])   # Pyth
Eslatma: slicingda oxirgi index olinmaydi. soz[0:3] 0, 1 va 2-indexlarni, ya’ni Pyt ni qaytaradi.

5. String formatlash

O‘zgaruvchilarni matn ichiga chiroyli joylashtirish formatlash deyiladi.

1-usul: vergul bilan print()

ism = "Lola"
yosh = 17
print("Mening ismim", ism, "va yoshim", yosh)

2-usul: + bilan birlashtirish

print("Mening ismim " + ism)
Kamchiligi: sonni + bilan stringga qo‘sha olmaysiz. str(yosh) kerak bo‘ladi. Shu sababli f-string qulayroq.

3-usul: f-string — tavsiya etiladi

ism = "Lola"
yosh = 17
baho = 4.75
print(f"Mening ismim {ism}, yoshim {yosh} da.")
print(f"O‘rtacha bahom: {baho:.2f}")

f harfi va { } ichida o‘zgaruvchi yoziladi. {baho:.2f} kasrli sonni 2 xonagacha ko‘rsatadi.

4-usul: .format()

print("Mening ismim {}, yoshim {}".format(ism, yosh))
print("Ism: {0}, Yosh: {1}".format(ism, yosh))

6. Asosiy string metodlari

Metodlar string bilan ishlashni osonlashtiradigan tayyor buyruqlardir.

MetodVazifasiMisol
upper()Hamma harfni katta qiladi"salom".upper() → SALOM
lower()Hamma harfni kichik qiladi"SALOM".lower() → salom
title()Har bir so‘z boshini katta qiladi"ali vali".title()
capitalize()Faqat birinchi harfni katta qiladi"salom dunyo".capitalize()
strip()Bosh va oxirdagi bo‘sh joylarni o‘chiradi" salom ".strip()
replace()Matn qismini almashtiradi"salom".replace("a", "o")
split()Matnni listga ajratadi"olma,anor".split(",")
join()Listni bitta stringga birlashtiradi"-".join(["a","b"])
find()Qidirilgan qismning indexini topadi"Python".find("t")
count()Qism necha marta kelganini sanaydi"olma".count("a")
startswith()String shu qism bilan boshlanishini tekshiradi"salom".startswith("sa")
endswith()String shu qism bilan tugashini tekshiradi"file.py".endswith(".py")

7. Metodlar amalda

matn = "  python dasturlash tili  "
print(matn.strip())
print(matn.upper())
print(matn.strip().title())
print(matn.replace("python", "Java"))
print(matn.count("a"))

Bir nechta metodni zanjir kabi ishlatish mumkin: matn.strip().title().

ism = ism.strip().title()
