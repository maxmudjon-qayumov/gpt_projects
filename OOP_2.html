1. Oldingi bilimlarni aniqlashtirish

__init__ odatda “konstruktor” deyiladi, ammo texnik jihatdan tayyor obyektni boshlang‘ich holatga keltiradi. Obyektni yaratish vazifasi __new__ga tegishli. Ko‘p loyihalarda __new__ni qayta yozish talab qilinmaydi.

Class ham obyekt: type(MyClass) odatda type bo‘ladi. obj = MyClass(...) instance yaratadi, other = obj esa nusxa yaratmasdan shu obyektga yana bir havola beradi.

class User:
    def __init__(self, name):
        self.name = name

a = User("Ali")
b = a
c = User("Ali")
print(a is b)  # True: bitta obyekt
print(a is c)  # False: boshqa obyekt
print(a == c)  # False: User qiymat tengligini hali belgilamagan

“Double underscore” — ikki pastki chiziq: __len__, __str__. Python odatiy amallarni bajarishda shu maxsus metodlarni chaqiradi. Ularni odatda classda belgilab, tashqarida len(obj) kabi tabiiy sintaksisdan foydalanamiz.

3. __str__ va __repr__

class Product:
    def __init__(self, name, price):
        self.name = name
        self.price = price

    def __str__(self):
        return f"{self.name}: {self.price} so‘m"

    def __repr__(self):
        return f"Product(name={self.name!r}, price={self.price!r})"

p = Product("Kitob", 50000)
print(p)        # Kitob: 50000 so‘m
print(repr(p))  # Product(name='Kitob', price=50000)
print([p])      # [Product(name='Kitob', price=50000)]

str foydalanuvchi uchun, repr dasturchi uchun qulay tavsif beradi. Ikkalasi ham string qaytarishi kerak. !r f-stringda qiymatning repr ko‘rinishini oladi. Maxfiy token/parollarni ushbu metodlarga kiritmang.

4. Operator, NotImplemented va hash

class Vector:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __add__(self, other):
        if not isinstance(other, Vector):
            return NotImplemented
        return Vector(self.x + other.x, self.y + other.y)

    def __eq__(self, other):
        if not isinstance(other, Vector):
            return NotImplemented
        return (self.x, self.y) == (other.x, other.y)

    def __repr__(self):
        return f"Vector({self.x}, {self.y})"

print(Vector(1, 2) + Vector(3, 4))  # Vector(4, 6)
print(Vector(1, 2) == Vector(1, 2)) # True

NotImplemented — mos bo‘lmagan operand uchun Pythonning boshqa mexanizmni sinashiga imkon beruvchi qiymat. U NotImplementedError exceptionidan farq qiladi. a + bda zarur bo‘lsa o‘ng operandning __radd__i tekshiriladi; += uchun __iadd__ mavjud.

__eq__ yozilib, __hash__ yozilmasa, instance odatda hashable bo‘lmaydi. Teng obyektlar bir xil hash berishi, hashga ta’sir qiladigan holat esa o‘zgarmas bo‘lishi kerak. Mutable narx yoki balans asosida hash tuzmang.

5. Kolleksiya va iterator protokoli

class Cart:
    def __init__(self, items):
        self._items = list(items)

    def __len__(self):
        return len(self._items)

    def __getitem__(self, index):
        return self._items[index]

    def __contains__(self, item):
        return item in self._items

    def __iter__(self):
        return iter(self._items)

cart = Cart(["kitob", "ruchka"])
print(len(cart))          # 2
print(cart[0])            # kitob
print(cart[:1])           # ['kitob']
print("kitob" in cart)    # True
print(bool(Cart([])))     # False: __bool__ yo‘q, __len__ ishlaydi
print(list(cart))         # ['kitob', 'ruchka']

Iterable __iter__dan iterator qaytaradi. Iteratorning __next__i navbatdagi qiymatni, tugaganda StopIterationni beradi. Quyidagi yield asosidagi metod generator yaratib shu protokolni o‘zi bajaradi:

class Countdown:
    def __init__(self, start):
        self.start = start

    def __iter__(self):
        for number in range(self.start, 0, -1):
            yield number

print(list(Countdown(3)))  # [3, 2, 1]

Kolleksiyada har safar yangi iterator qaytarish uni qayta aylanishga imkon beradi. Obyekt o‘zini iterator sifatida qaytarsa, uning ichki pozitsiyasi tugashi mumkin.

6. __call__: obyektni funksiya kabi chaqirish

class MinimumLength:
    def __init__(self, minimum):
        self.minimum = minimum

    def __call__(self, text):
        return len(text) >= self.minimum

valid = MinimumLength(3)
print(valid("hi"))     # False
print(valid("salom"))  # True

Bu sozlanadigan validator, callback yoki strategiya uchun qulay. Oddiy stateless hisob uchun funksiya yetarli.

7. Context manager va resurs hayoti

class Session:
    def __enter__(self):
        print("Resurs ochildi")
        return self

    def __exit__(self, exc_type, exc_value, traceback):
        print("Resurs yopildi")
        return False  # exceptionni yashirmaslik

with Session():
    print("Ish bajarildi")
# Resurs ochildi
# Ish bajarildi
# Resurs yopildi

__enter__ qaytargan qiymat with ... as valuega beriladi. __exit__ True qaytarsa exception bostiriladi. __enter__ning o‘zi xato bersa, shu obyektning __exit__i chaqirilmaydi: qisman ochilgan resursni tozalashni hisobga oling.

del obj havolani olib tashlaydi; obyekt darhol yo‘q qilinishiga kafolat yo‘q. __del__ga tayanib fayl yoki DB ulanishini yopmang. with va explicit close() aniqroq boshqaruv beradi.

8. Instance, class va static methodlar

class User:
    def __init__(self, name):
        self.name = name

    def greet(self):  # instance holati
        return f"Salom, {self.name}"

    @classmethod
    def from_dict(cls, data):  # muqobil yaratish usuli
        return cls(data["name"])

    @staticmethod
    def is_valid_name(name):  # self ham, cls ham yo‘q
        return isinstance(name, str) and bool(name.strip())

u = User.from_dict({"name": "Ali"})
print(u.greet())                  # Salom, Ali
print(User.is_valid_name("  "))   # False

self instance, cls classning o‘zi. classmethod ichida cls(...) ishlatish child classlarda ham mos instance yaratadi. staticmethod class mavzusiga tegishli yordamchi funksiyaga mos; modul funksiyasi ham yaxshi variant.

9. Nusxa olish: assignment, copy, deepcopy

from copy import copy, deepcopy

class Group:
    def __init__(self):
        self.names = ["Ali"]

a = Group()
alias = a
shallow = copy(a)
deep = deepcopy(a)
a.names.append("Lola")
print(alias is a)           # True
print(shallow.names)       # ['Ali', 'Lola']
print(deep.names)          # ['Ali']

Yuzaki nusxa tashqi obyektni ajratadi, nested obyektlar umumiy qoladi. Deepcopy rekursiv nusxa qiladi, ammo database ulanishi, lock, socket kabi resurslar uchun universal yechim emas. Zarur bo‘lsa __copy__/__deepcopy__ bilan xulq belgilanadi.

10. Dataclass: ma’lumot obyektlarini ixcham yozish

from dataclasses import dataclass, field, asdict, replace

@dataclass
class User:
    name: str
    skills: list[str] = field(default_factory=list)

    def __post_init__(self):
        if not self.name.strip():
            raise ValueError("Ism bo‘sh bo‘lmasin")

a = User("Ali")
b = replace(a, name="Lola")
print(a)         # User(name='Ali', skills=[])
print(asdict(a)) # {'name': 'Ali', 'skills': []}
print(b.name)    # Lola

Dataclass __init__, __repr__ va qiymat tengligini generatsiya qiladi. __post_init__ boshlang‘ich tekshiruvga mos. Type hintlar avtomatik runtime validatsiya bermaydi. replace() ham har nested qiymatni deep copy qilmaydi.

frozen=True attribute qayta berilishini cheklaydi, nested listni muzlatmaydi. slots=True instance tuzilishini ixchamlashtiradi. kw_only=True parametrlarni nom bilan berishni talab qiladi; order=True taqqoslash metodlarini yaratadi.

from dataclasses import dataclass

@dataclass(frozen=True)
class ProductKey:
    sku: str
    currency: str

stock = {ProductKey("BOOK", "UZS"): 5}
print(stock[ProductKey("BOOK", "UZS")])  # 5

asdict() nested dataclasslarni dictga aylantiradi, lekin datetime/Decimal kabi qiymatlarni avtomatik JSON string qilmaydi.

11. Classni JSONga saqlash nimani anglatadi?

JSONga class kodi yoki methodlar emas, instance holati saqlanadi. Qayta o‘qiganda shu holatdan yangi instance yaratiladi. JSON string, son, bool, null, array va string kalitli objectni biladi.

12. To‘liq loyiha: obyekt → JSON fayl → obyekt

Quyidagi mustaqil kod vaqtinchalik papkada JSON yaratadi, o‘qiydi va tozalaydi. Real doimiy saqlashda pathni loyiha data papkasiga yo‘naltiring. Misol Python standart kutubxonasi bilan ishlaydi.

import json
from dataclasses import dataclass
from datetime import datetime, timezone
from decimal import Decimal, InvalidOperation
from enum import Enum
from pathlib import Path
from tempfile import TemporaryDirectory

class Status(Enum):
    ACTIVE = "active"
    ARCHIVED = "archived"

@dataclass
class Product:
    name: str
    price: Decimal
    created_at: datetime
    status: Status = Status.ACTIVE

    def __post_init__(self):
        if not isinstance(self.name, str) or not self.name.strip():
            raise ValueError("name bo‘sh bo‘lmagan matn bo‘lsin")
        if not isinstance(self.price, Decimal):
            raise TypeError("price Decimal bo‘lsin")
        if not self.price.is_finite() or self.price < 0:
            raise ValueError("price chekli, manfiy bo‘lmagan son bo‘lsin")
        if not isinstance(self.created_at, datetime):
            raise TypeError("created_at datetime bo‘lsin")
        if self.created_at.utcoffset() is None:
            raise ValueError("Vaqt zonasi kerak")
        if not isinstance(self.status, Status):
            raise TypeError("status Status bo‘lsin")

    def to_dict(self):
        return {
            "name": self.name,
            "price": str(self.price),
            "created_at": self.created_at.isoformat(),
            "status": self.status.value,
        }

    @classmethod
    def from_dict(cls, data):
        if not isinstance(data, dict):
            raise ValueError("Mahsulot object bo‘lsin")
        expected = {"name", "price", "created_at", "status"}
        if set(data) != expected:
            raise ValueError("Maydonlar noto‘g‘ri")
        if not all(isinstance(data[key], str) for key in expected):
            raise ValueError("Saqlangan maydonlar string bo‘lsin")
        try:
            price = Decimal(data["price"])
            date = datetime.fromisoformat(data["created_at"])
            status = Status(data["status"])
        except (ValueError, InvalidOperation) as exc:
            raise ValueError("Mahsulot formati noto‘g‘ri") from exc
        return cls(data["name"], price, date, status)

def save_products(path, products):
    payload = {
        "schema_version": 1,
        "products": [product.to_dict() for product in products],
    }
    # "w" mavjud faylni almashtiradi.
    with path.open("w", encoding="utf-8") as file:
        json.dump(payload, file, ensure_ascii=False,
                  indent=2, allow_nan=False)

def load_products(path):
    with path.open(encoding="utf-8") as file:
        payload = json.load(file)
    if not isinstance(payload, dict):
        raise ValueError("Ildiz JSON object bo‘lsin")
    if set(payload) != {"schema_version", "products"}:
        raise ValueError("Fayl maydonlari noto‘g‘ri")
    if type(payload["schema_version"]) is not int or payload["schema_version"] != 1:
        raise ValueError("Schema versiyasi qo‘llanmaydi")
    if not isinstance(payload["products"], list):
        raise ValueError("products ro‘yxat bo‘lsin")
    return [Product.from_dict(item) for item in payload["products"]]

def main():
    original = Product(
        "Kitob", Decimal("25.50"),
        datetime(2026, 10, 1, 10, 0, tzinfo=timezone.utc),
    )
    with TemporaryDirectory() as directory:
        path = Path(directory) / "products.json"
        save_products(path, [original])
        restored = load_products(path)[0]
        print(restored == original)       # True
        print(restored is original)       # False
        print(type(restored).__name__)   # Product
        print(restored.price)             # 25.50
        print(restored.status.value)      # active

if __name__ == "__main__":
    main()

json.load() dict/list qaytaradi; from_dict()gina uni Productga tiklaydi. Buzilgan JSON JSONDecodeError, mavjud bo‘lmagan fayl FileNotFoundError, noto‘g‘ri schema ValueError beradi. Chaqiruvchi qatlam bu xatolarni aniq boshqarsin; buzilgan fayl o‘rniga avtomatik bo‘sh ro‘yxat yozib yubormang.

Fayl formati o‘zgarsa schema_versionni oshirib, eski formatni ko‘chirish qoidasi yoziladi. JSON obyektlar identifikatsiyasini, umumiy havolalarni yoki siklik bog‘lanishlarni saqlamaydi. Katta va bir nechta worker yozadigan backend uchun database va transaction kerak.

13. JSONEncoder, Pydantic va pickle

Maxsus encoder json.dumps(data, default=encode) orqali ulanganda tanilmagan qiymatni JSONga mos ko‘rinishga aylantiradi. Decoder obyektni avtomatik tiklamaydi — tiklash qoidasi alohida kerak.

import json
from decimal import Decimal

def encode(value):
    if isinstance(value, Decimal):
        return str(value)
    raise TypeError(f"Qo‘llanmaydigan tur: {type(value).__name__}")

text = json.dumps({"price": Decimal("12.50")}, default=encode)
print(text)  # {"price": "12.50"}

Shu mantiqni json.JSONEncoder subclassining default() metodida ham yozish mumkin. default=str hamma noma’lum turni matnga yashirib yuboradi; bu noto‘g‘ri formatni sezishni qiyinlashtiradi.

Pydantic darsida ko‘rsatilganidek, model uchun model_dump_json() va Model.model_validate_json() qo‘llanadi. Oddiy class, dataclass va Pydantic model bir xil emas. pickle Python obyektlariga xos format, ammo ishonchsiz pickle faylini yuklash kod bajarilishiga olib kelishi mumkin; tashqi API/fayl almashishda JSON va aniq schema qulay.

14. Composition va dependency injection

Order service ichida email yuboruvchi obyekt bo‘lishi — “has-a” aloqasi. Servicega ushbu obyektni tashqaridan berish dependency injection deyiladi. Testda haqiqiy tarmoq o‘rniga soxta yuboruvchini berish mumkin.

class ConsoleSender:
    def send(self, text):
        print(text)

class OrderService:
    def __init__(self, sender):
        self.sender = sender

    def confirm(self, order_id):
        self.sender.send(f"Buyurtma {order_id} tasdiqlandi")

service = OrderService(ConsoleSender())
service.confirm(7)  # Buyurtma 7 tasdiqlandi

Class boshqa classning turi bo‘lsa inheritance, uning xizmatidan foydalansa composition mos keladi. Aggregationda obyektlar mustaqil hayotga ega bo‘lishi mumkin; compositionda egasi ularning hayotini boshqarishi ko‘zda tutiladi. Python bu egalikni majburan cheklamaydi.

15. Protocol, ABC va type hint

from typing import Protocol

class Sender(Protocol):
    def send(self, text: str) -> None: ...

class ConsoleSender:
    def send(self, text: str) -> None:
        print(text)

def notify(sender: Sender) -> None:
    sender.send("Salom")

notify(ConsoleSender())  # Salom

Protocol strukturani tavsiflaydi: explicit meros olish shart emas. U asosan static type checker uchun; Python runtime’da argument turini avtomatik tekshirmaydi. @runtime_checkable mavjud a’zolarni sodda tekshiradi, signatura va type hintlarni to‘liq tekshirmaydi. ABC abstract metodlarni implement qilish talabini runtime instantiationda qo‘yadi.

16. MRO, super va mixin

class Base:
    def label(self):
        return ["Base"]

class AuditMixin(Base):
    def label(self):
        return ["Audit"] + super().label()

class Service(Base):
    def label(self):
        return ["Service"] + super().label()

class App(AuditMixin, Service):
    pass

print(App().label())  # ['Audit', 'Service', 'Base']
print([c.__name__ for c in App.__mro__])
# ['App', 'AuditMixin', 'Service', 'Base', 'object']

super() doim “to‘g‘ridan-to‘g‘ri parent” emas, MROdagi keyingi implementatsiyaga o‘tadi. Cooperative multiple inheritance uchun signaturalar mos, super chaqiruvlari izchil bo‘lsin. Mixin kichik qo‘shimcha imkoniyat bersin; bir-biriga zid murakkab holatni yashirmasin.

17. __slots__, attributelar va descriptor

__slots__ = ("name", "age") instance maydonlarini oldindan belgilab, ko‘pincha __dict__ni olib tashlaydi. Bu ko‘p obyektlarda xotirani tejashi mumkin; private himoya yoki immutablelik emas. Meros olishda parentning __dict__i bo‘lsa natija farq qiladi.

getattr(obj, "name", default), setattr, hasattr dinamik attribute ishlatish uchun. __getattr__ oddiy qidiruv muvaffaqiyatsiz bo‘lganda, __getattribute__ esa har kirishda ishlaydi. Ikkinchisini noto‘g‘ri yozish rekursiyaga olib keladi.

Descriptor: qayta ishlatiladigan propertyga o‘xshash qoida

class Positive:
    def __set_name__(self, owner, name):
        self.storage_name = "_" + name

    def __get__(self, instance, owner=None):
        if instance is None:
            return self
        return getattr(instance, self.storage_name)

    def __set__(self, instance, value):
        if type(value) is not int or value <= 0:
            raise ValueError("Musbat int kerak")
        setattr(instance, self.storage_name, value)

class Stock:
    quantity = Positive()

    def __init__(self, quantity):
        self.quantity = quantity

stock = Stock(5)
print(stock.quantity)  # 5
# stock.quantity = 0  # ValueError

Descriptorlar __get__, __set__, __delete__ orqali attribute kirishini boshqaradi. Property va method binding ham shu mexanizmlar bilan bog‘liq. Oddiy bitta attribute uchun propertydan boshlash osonroq.

18. Class lifecycle: __init_subclass__ va metaclass

class Plugin:
    registry = {}

    def __init_subclass__(cls, *, key, **kwargs):
        super().__init_subclass__(**kwargs)
        if key in Plugin.registry:
            raise ValueError("Plugin kaliti takror")
        Plugin.registry[key] = cls

class CsvPlugin(Plugin, key="csv"):
    pass

print(Plugin.registry["csv"] is CsvPlugin)  # True

__init_subclass__ child class ta’riflanganda ishlaydi; registratsiya va class qoidalariga mos. Metaclass classning o‘zini yaratish mexanizmini boshqaradi: odatda type. Ko‘p vazifani class decorator yoki __init_subclass__ bilan bajarish mumkin; metaclass framework dizayni darajasida kerak bo‘ladi.

20. OOP dizayni va testlash

SOLID yo‘nalishi: classning vazifasi aniq bo‘lsin (S); yangi behavior qo‘shish oson bo‘lsin (O); child parent shartnomasini buzmasin (L); interfeyslar kerakli darajada kichik bo‘lsin (I); yuqori darajadagi kod konkret xizmatdan ko‘ra shartnomaga bog‘lansin (D).

Repository saqlash/o‘qish, Service biznes qoidasi, DTO ma’lumot tashish vazifasini bajaradi. Bu qatlamlarni faqat loyiha ehtiyoji bo‘lganda kiriting. Har narsani classga aylantirish shart emas.

JSON loyihasini testlash: round-trip qiymatlar tengligini, yangi instance ekanini, noto‘g‘ri price/status/schema rad etilishini tekshiring. Dependency injection bilan email yoki database o‘rniga oddiy fake obyekt ishlating.
