BOSHLANG‘ICH DARAJA · 1-DARS

IT olamiga ilk qadam va Python bilan tanishuv

Bu darsda kompyuter qanday ishlashi, dasturlar nima ekanligi va Python’da birinchi kodni yozishni o‘rganamiz.

Dars maqsadi

Dars oxirida siz IT, hardware, software va dasturlash tili tushunchalarini farqlay olasiz; PyCharm’ni o‘rnatasiz hamda ilk Python dasturingizni ishga tushirasiz.

1. IT nima?

IT — Information Technology, ya’ni axborot texnologiyalari degani. IT yordamida ma’lumotlarni yaratamiz, saqlaymiz, qayta ishlaymiz va internet orqali ulashamiz.

Ma’lumot→Kompyuter→Dastur→Natija

Masalan, telefoningizdagi Telegram, bank ilovasi, veb-saytlar va o‘yinlarning barchasi IT mahsulotidir.

2. Hardware va Software

Kompyuterni ikki katta qismga ajratish mumkin: ushlab ko‘rish mumkin bo‘lgan qurilmalar va ularni boshqaradigan dasturlar.

🖥️

Hardware — qurilma qismi

Ko‘rish va ushlash mumkin bo‘lgan jismoniy qismlar. Masalan: monitor, klaviatura, sichqoncha, protsessor, xotira (RAM), qattiq disk.

💿

Software — dasturiy qism

Kompyuterga nima qilishni buyuradigan dasturlar. Masalan: Windows, Chrome, Word, Telegram, o‘yinlar va Python dasturlari.

Esda tuting: hardware — tanasi, software esa uning “aqli” yoki ko‘rsatmalaridir. Ikkalasi birgalikda ishlaydi.

3. Dasturlash tili nima?

Dasturlash tili — dasturchi kompyuterga aniq buyruqlar yozishi uchun ishlatiladigan til. Kompyuter faqat juda aniq ko‘rsatmalarni bajaradi, shuning uchun kod yozish qoidalariga amal qilinadi.

Inson yozadi

Dasturchi kod yozadi: print("Salom")

Kompyuter bajaradi

Python kodni tushunib, ekranga Salom so‘zini chiqaradi.

Mashhur dasturlash tillari: Python, JavaScript, Java, C++, C#. Ularning har biri turli vazifalarda qo‘llanadi.

4. Nega Python?

Python — o‘rganishga qulay, sodda va juda mashhur dasturlash tili. Uning kodlari inson tiliga yaqin bo‘lgani uchun yangi boshlovchilar uchun ayni muddao.

Qayerda ishlatiladi?

Veb-saytlar, Telegram botlar, sun’iy intellekt, ma’lumotlar tahlili, avtomatlashtirish va o‘yinlarda.

Afzalligi

Yozilishi oson, katta hamjamiyatga ega va ko‘plab tayyor kutubxonalari mavjud.

5. PyCharm nima?

PyCharm — Python kodlarini yozish, tekshirish va ishga tushirish uchun yaratilgan dastur. Bunday dastur IDE (Integrated Development Environment) deb ataladi.

PyCharm koddagi xatolarni ko‘rsatadi, fayllarni tartiblaydi va dasturni ishga tushirishni osonlashtiradi.

Muhim: PyCharm kod yozish muhiti, Python esa kodni bajaradigan dasturlash tili. Ikkalasini ham o‘rnatish kerak.

6. Python va PyCharm o‘rnatish

A. Python’ni o‘rnatish

  1. Brauzerda python.org/downloads saytini oching.
  2. Download Python tugmasini bosing va yuklangan faylni ishga tushiring.
  3. Eng pastdagi Add Python to PATH belgisini albatta qo‘ying.
  4. Install Now tugmasini bosing va o‘rnatish tugashini kuting.

B. PyCharm Community’ni o‘rnatish

  1. jetbrains.com/pycharm/download saytiga kiring.
  2. Community Edition (bepul) versiyasini yuklab oling.
  3. O‘rnatish faylini oching va odatiy sozlamalar bilan davom eting.
  4. PyCharm’ni oching, New Project tugmasini bosing va Python Interpreter tanlanganini tekshiring.

7. Birinchi dastur: Hello, World!

Yangi loyiha ichida main.py nomli fayl yarating. So‘ng quyidagi kodni yozing:

main.py
print("Hello, World!")

print() — ekranga ma’lumot chiqarish buyrug‘i. Qo‘shtirnoq ichidagi matn aynan ekranga chiqadi.

  1. Kodni saqlang: Ctrl + S.
  2. Fayl ichida sichqonchaning o‘ng tugmasini bosing.
  3. Run 'main' bandini tanlang yoki yuqoridagi yashil ▶ tugmani bosing.
  4. Pastdagi konsolda Hello, World! yozuvi paydo bo‘ladi.
