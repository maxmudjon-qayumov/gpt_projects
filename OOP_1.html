1. OOP nima?

OOP — Object-Oriented Programming, ya’ni obyektga yo‘naltirilgan dasturlash. Bu usul dastur kodini obyektlar atrofida tashkil qilishga yordam beradi.

Obyektning odatda ikki tomoni bo‘ladi:

📦

Holati (state)

Obyektning ma’lumotlari: foydalanuvchi ismi, emaili, mahsulot narxi, avtomobil rangi.

⚙️

Xatti-harakati (behavior)

Obyekt bajaradigan ishlar: login qilish, narx hisoblash, avtomobilni ishga tushirish.

Oddiy misol: “Avtomobil” obyektining holati — marka, rang, tezlik; xatti-harakati — yurish, to‘xtash, signal berish.

5. Attribute: object ma’lumotlari

Attribute — objectga tegishli qiymat. Uni object yaratilgandan keyin ham berish mumkin, ammo odatda __init__ ichida beriladi.

class User:
    pass

ali = User()
ali.name = "Ali"
ali.email = "ali@mail.com"
ali.age = 21

print(ali.name)   # Ali
print(ali.email)  # ali@mail.com
Kamchiligi: bu usulda har objectga barcha attributelarni qo‘lda qo‘shish kerak. Buning o‘rniga konstruktor ishlatamiz.

6. __init__ konstruktori

__init__ — object yaratilishi bilan avtomatik ishlaydigan maxsus method. U objectning boshlang‘ich ma’lumotlarini belgilaydi.

class User:
    def __init__(self, name, email, age):
        self.name = name
        self.email = email
        self.age = age

ali = User("Ali", "ali@mail.com", 21)
lola = User("Lola", "lola@mail.com", 19)

print(ali.name)   # Ali
print(lola.email) # lola@mail.com

7. self nima?

self — class ichidagi aynan qaysi object bilan ishlayotganimizni bildiradi. Har instance methodning birinchi parametri bo‘lishi kerak.

class User:
    def __init__(self, name):
        self.name = name

    def introduce(self):
        print(f"Mening ismim {self.name}")

ali = User("Ali")
lola = User("Lola")

ali.introduce()   # Mening ismim Ali
lola.introduce()  # Mening ismim Lola

ali.introduce() chaqirilganda Python yashirin tarzda User.introduce(ali) kabi ishlaydi. Shu sababli method ichidagi self.name — ali.name bo‘ladi.

8. Method nima?

Method — class ichida yozilgan funksiya. U object attribute’lariga self orqali kira oladi va ularni o‘zgartira oladi.

class Product:
    def __init__(self, name, price, stock):
        self.name = name
        self.price = price
        self.stock = stock

    def show_info(self):
        return f"{self.name}: {self.price} so‘m, omborda: {self.stock}"

    def is_available(self):
        return self.stock > 0

phone = Product("Telefon", 2500000, 5)
print(phone.show_info())      # Telefon: 2500000 so‘m, omborda: 5
print(phone.is_available())   # True
Qoida: attribute — objectdagi ma’lumot; method — object bajaradigan harakat.

9. Attribute qiymatini o‘zgartirish

class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        if amount > 0:
            self.balance += amount
            return f"Balans: {self.balance}"
        return "Miqdor musbat bo‘lishi kerak"

account = BankAccount("Ali", 100)
print(account.deposit(50))  # Balans: 150
print(account.balance)      # 150

Method objectning ichki holatini o‘zgartirdi. Keyingi OOP darslarida bunday qiymatlarni to‘g‘ridan-to‘g‘ri o‘zgartirishdan himoyalashni o‘rganamiz.

10. Class attribute va instance attribute

Instance attribute har objectga alohida tegishli. Class attribute esa classdan yaratilgan barcha objectlar uchun umumiy.

class User:
    platform = "My Backend"  # class attribute

    def __init__(self, name):
        self.name = name      # instance attribute

ali = User("Ali")
lola = User("Lola")

print(ali.platform)  # My Backend
print(lola.platform) # My Backend
print(ali.name)      # Ali
Ehtiyot bo‘ling: class attribute sifatida [] yoki {} kabi o‘zgaruvchan qiymat berish ko‘pincha xato olib keladi. U barcha objectlarda umumiy bo‘lib qoladi.

12. Backend amaliy loyiha: User modeli

class User:
    def __init__(self, user_id, username, email, is_active=True):
        self.user_id = user_id
        self.username = username
        self.email = email
        self.is_active = is_active

    def get_public_data(self):
        return {
            "id": self.user_id,
            "username": self.username,
            "email": self.email,
            "active": self.is_active
        }

    def deactivate(self):
        self.is_active = False
        return f"{self.username} profili deaktiv qilindi"

ali = User(1, "ali_dev", "ali@mail.com")
print(ali.get_public_data())
print(ali.deactivate())
print(ali.get_public_data())
