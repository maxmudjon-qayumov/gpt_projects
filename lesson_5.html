int va float

Ulardan biri float bo‘lsa, arifmetik natija odatda float bo‘ladi.

print(5 + 2.5)  # 7.5     → float
print(5 * 2.5)  # 12.5    → float
print(5 // 2.5) # 2.0     → float
print(5 % 2.5)  # 0.0     → float

bool va sonlar

Python’da True son sifatida 1, False esa 0 ga teng hisoblanadi.

print(True + 5)     # 6
print(False * 10)   # 0
print(True * 3.5)   # 3.5
Bu mumkin bo‘lsa ham, kodni tushunarli saqlash uchun bool qiymatlarini asosan shartlarda ishlatish tavsiya etiladi.

5. Operatorlar ustuvorligi

Bir qatorda bir nechta operator bo‘lsa, Python quyidagi ketma-ketlikda bajaradi:

  1. Qavslar: ()
  2. Daraja: **
  3. Ko‘paytirish, bo‘lish, qoldiq: * / // %
  4. Qo‘shish va ayirish: + -
print(2 + 3 * 4)     # 14, avval 3 * 4
print((2 + 3) * 4)   # 20, avval qavs ichidagi amal
print(2 ** 3 * 2)    # 16
Maslahat: Agar tartib noaniq bo‘lsa, qavs ishlating. Kod aniq va o‘qish oson bo‘ladi.
