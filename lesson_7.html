2. for sikli

for list, string, tuple, dictionary yoki range() ichidagi elementlarni navbatma-navbat oladi.

for o_zgaruvchi in kolleksiya:
    bajariladigan_kod
mevalar = ["olma", "banan", "anor"]

for meva in mevalar:
    print(meva)

Natija:

olma
banan
anor

Har aylanishda meva o‘zgaruvchisiga navbatdagi element tushadi.

String bo‘yicha for

for harf in "Python":
    print(harf)

Natija: P, y, t, h, o, n — har biri yangi qatorda.

3. range() bilan for

range() sonlar ketma-ketligini yaratadi. U ko‘pincha for sikli bilan ishlatiladi.

4. enumerate() — index va qiymat

Ro‘yxatdagi elementning indexi ham kerak bo‘lsa, enumerate() dan foydalaniladi.

for index, fan in enumerate(fanlar):
    print(index, fan)

Natija:

0 Python
1 Django
2 PostgreSQL

Sanashni 1 dan boshlash: enumerate(fanlar, start=1).

5. while sikli

while ichidagi shart True bo‘lib turguncha kod takrorlanadi.

while shart:
    bajariladigan_kod
son = 1

while son <= 5:
    print(son)
    son = son + 1

Natija: 1, 2, 3, 4, 5.

Eng muhim xato — cheksiz sikl: agar son = son + 1 yozilmasa, son <= 5 doim rost qoladi. Dastur to‘xtamaydi. Uni to‘xtatish uchun terminalda Ctrl + C bosing.

Foydalanuvchi kiritishi bilan while

parol = ""

while parol != "python123":
    parol = input("Parolni kiriting: ")

print("Xush kelibsiz!")

To‘g‘ri parol kiritilmaguncha dastur so‘rayveradi.

6. break, continue va else

BuyruqVazifasi
breakSiklni darhol butunlay to‘xtatadi.
continueJoriy aylanishni o‘tkazib yuborib, keyingisiga o‘tadi.
elseSikl break siz tabiiy yakunlansa bajariladi.
# break misoli
for son in range(1, 10):
    if son == 5:
        break
    print(son)
# Natija: 1, 2, 3, 4
# continue misoli
for son in range(1, 6):
    if son == 3:
        continue
    print(son)
# Natija: 1, 2, 4, 5
# for-else misoli
sonlar = [3, 7, 11]
for son in sonlar:
    if son == 5:
        print("5 topildi")
        break
else:
    print("5 topilmadi")

7. Bir qatorli for (one-line for)

Juda sodda sikl tanasini bir qatorda yozish mumkin. Bu usul qisqa amallar uchun qulay, lekin murakkab kodda oddiy ko‘p qatorli usul tushunarliroq.

for son in range(1, 6): print(son)

Natija: 1 dan 5 gacha sonlar yangi qatorda chiqadi.

mevalar = ["olma", "anor", "uzum"]
for meva in mevalar: print(meva.upper())
Maslahat: bir qatorli for ichida faqat bitta, juda qisqa amal bo‘lsa ishlating. if, hisoblash va bir nechta buyruq bo‘lsa kodni alohida qatorlarga yozing.

8. List comprehension nima?

List comprehension — for yordamida yangi list yaratishning qisqa usuli. U bir qatorli kodda ro‘yxatni o‘zgartirish yoki filtrlash imkonini beradi.

[ifoda for element in kolleksiya]
sonlar = [1, 2, 3, 4, 5]
kvadratlar = [son ** 2 for son in sonlar]
print(kvadratlar)

Natija: [1, 4, 9, 16, 25].

Oddiy for bilan bir xil kod

Oddiy for

kvadratlar = []
for son in sonlar:
    kvadratlar.append(son ** 2)

List comprehension

kvadratlar = [son ** 2
               for son in sonlar]
Ikkala variant ham bir xil natija beradi. List comprehension ixcham, oddiy for esa murakkab mantiqda o‘qishga qulayroq.

9. List comprehension ichida if

Oxiridagi if — filter. Shart rost bo‘lgan elementlargina yangi listga kiradi.

[ifoda for element in kolleksiya if shart]
sonlar = [1, 2, 3, 4, 5, 6]
juft_sonlar = [son for son in sonlar if son % 2 == 0]
print(juft_sonlar)

Natija: [2, 4, 6].

foydalanuvchilar = ["ali", "", "lola", " ", "umar"]
faol_ismlar = [ism.strip().title() for ism in foydalanuvchilar if ism.strip()]
print(faol_ismlar)

Natija: ["Ali", "Lola", "Umar"]. Bo‘sh qiymatlar filtrdan o‘tmaydi.

Kod qismiVazifasi
son for son in sonlarHar sonni yangi listga qo‘shishga tayyorlaydi
if son % 2 == 0Faqat juft sonlarni qoldiradi

10. List comprehension ichida if else

if else boshida yozilsa, u har bir element uchun tanlov qiladi: ikkala holatda ham element listga qo‘shiladi, lekin qiymati turlicha bo‘ladi.

[true_holat if shart else false_holat for element in kolleksiya]
sonlar = [1, 2, 3, 4, 5]
natija = ["juft" if son % 2 == 0 else "toq" for son in sonlar]
print(natija)

Natija: ["toq", "juft", "toq", "juft", "toq"].

baholar = [95, 72, 49, 88]
holatlar = ["o‘tdi" if baho >= 60 else "yiqildi" for baho in baholar]
print(holatlar)

Natija: ["o‘tdi", "o‘tdi", "yiqildi", "o‘tdi"].

Farqni eslang:
[son for son in sonlar if son % 2 == 0] — faqat juftlarni oladi (filter).
["juft" if son % 2 == 0 else "toq" for son in sonlar] — barcha sonlar uchun yangi nom yaratadi (tanlov).

11. Backend misoli: API foydalanuvchilarini tayyorlash

Backendda API dan foydalanuvchilar ro‘yxati kelganini tasavvur qiling. Faqat faol foydalanuvchilarning emailini olish mumkin:

users = [
    {"name": "Ali", "email": "ali@mail.com", "active": True},
    {"name": "Lola", "email": "lola@mail.com", "active": False},
    {"name": "Umar", "email": "umar@mail.com", "active": True}
]

active_emails = [user["email"] for user in users if user["active"]]
print(active_emails)

Natija: ["ali@mail.com", "umar@mail.com"].

# Har bir foydalanuvchiga holat biriktirish
statuses = ["active" if user["active"] else "inactive" for user in users]
print(statuses)
# ['active', 'inactive', 'active']
