2. Module yaratish va import qilish

Har qanday .py fayl module bo‘la oladi. Masalan, quyidagi ikkita faylni yarating:

# calculator.py
def qoshish(a, b):
    return a + b

def ayirish(a, b):
    return a - b
# main.py
import calculator

print(calculator.qoshish(10, 5))  # 15
print(calculator.ayirish(10, 5))  # 5

import calculator butun modulni import qiladi. Funksiyani chaqirishda modul nomi yoziladi.

5. Package tuzilmasi

Package — ichida Python modullari bo‘lgan papka. Zamonaviy Python’da __init__.py har doim shart emas, ammo uni qo‘shish package ni aniqroq ko‘rsatadi.

my_project/
├── main.py
├── app/
│   ├── __init__.py
│   ├── validators.py
│   └── services.py
└── requirements.txt
# app/validators.py
def validate_email(email):
    return "@" in email

# main.py
from app.validators import validate_email

print(validate_email("ali@mail.com"))  # True
Relative import: package ichida from .validators import validate_email yozish mumkin. Buni odatda package ichidagi modullar bir-birini import qilganda ishlating.

6. __name__ == "__main__"

Python faylni bevosita ishga tushirganda uning __name__ qiymati "__main__" bo‘ladi. Boshqa fayl import qilsa, qiymat modul nomi bo‘ladi.

# calculator.py
def qoshish(a, b):
    return a + b

if __name__ == "__main__":
    print(qoshish(2, 3))

Bu test qatori faqat python calculator.py bajarilganda chiqadi; import calculator qilinganda chiqmaydi.

7. Virtual environment (venv) nima?

Har loyiha turli kutubxona va versiyalarga muhtoj bo‘lishi mumkin. venv bu kutubxonalarni loyihaga alohida saqlaydi va boshqa loyihalarga ta’sir qilmasligini ta’minlaydi.

Misol: bir loyiha Django 4.x, boshqasi Django 5.x talab qilishi mumkin. Global o‘rnatish konflikt tug‘diradi; venv esa muammoni hal qiladi.

8. Windows’da venv yaratish va faollashtirish

Terminalni loyiha papkasida oching:

# 1. Virtual environment yaratish
py -m venv .venv

# 2. PowerShell uchun faollashtirish
.\.venv\Scripts\Activate.ps1

# CMD uchun faollashtirish
.venv\Scripts\activate.bat

# 3. Faollashgach, terminal boshida (.venv) chiqadi
(.venv) PS C:\my_project>

Faollashgan muhitdan chiqish: deactivate.

PowerShell xabari: agar script ishlatish bloklansa, PyCharm terminalidan foydalaning yoki administrator/IT sozlamalariga mos ruxsat bering. Xavfsizlik siyosatini o‘zgartirishdan avval uni tushunib oling.

10. requirements.txt

Loyihadagi kutubxonalar ro‘yxati requirements.txt ga yoziladi. Boshqa kompyuterda loyiha aynan shu kutubxonalar bilan ishga tushadi.

# requirements.txt yaratish
py -m pip freeze > requirements.txt

# requirements.txt ichidagilarni o‘rnatish
py -m pip install -r requirements.txt

Fayl ichiga misol:

fastapi==0.115.0
uvicorn==0.30.6
requests==2.32.3
Git qoidasi: .venv/ papkasini Git’ga qo‘shmang. Uni .gitignore ichiga yozing, ammo requirements.txt ni Git’ga qo‘shing.

11. PyCharm’da interpreter tanlash

  1. File → Settings → Project → Python Interpreter ga o‘ting.
  2. Interpreter tanlash yonidagi sozlama belgisini bosing.
  3. Add Local Interpreter ni tanlang.
  4. Loyihadagi .venv ni tanlang yoki yangi virtual environment yarating.
  5. Terminalda pip install ... qilsangiz, PyCharm ham shu interpreterni ishlatayotganini tekshiring.

12. Mini loyiha: modulga ajratilgan validator

project/
├── main.py
└── validators.py
# validators.py
def validate_email(email: str) -> bool:
    return "@" in email and "." in email.split("@")[-1]

def validate_password(password: str) -> bool:
    return len(password) >= 8
# main.py
from validators import validate_email, validate_password

email = input("Email: ")
password = input("Parol: ")

if validate_email(email) and validate_password(password):
    print("Ma’lumotlar qabul qilindi")
else:
    print("Email yoki parol noto‘g‘ri")
Mustaqil mashq: utils.py modulini yarating. Uning ichida format_price(price) va calculate_discount(price, percent) funksiyalarini yozing, keyin main.py dan import qilib ishlating.
