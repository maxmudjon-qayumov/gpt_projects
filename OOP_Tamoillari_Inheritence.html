OOP TAMOYILLARI · 1

Inheritance — meros olish

Parent classdagi xususiyat va methodlarni child classlarda qayta ishlatish hamda kengaytirishni o‘rganamiz.

Dars maqsadi

Inheritance yordamida umumiy kodni parent classga joylash, child classda undan foydalanish, super(), method overriding va ko‘p meros olishni tushunasiz.

1. Inheritance nima?

Inheritance (meros olish) — yangi class boshqa classning attribute va methodlarini olishi. Umumiy qism parent/base/super classda, unga xos qism child/derived/sub classda yoziladi.

Hayotiy misol

Vehicle umumiy class: brand, start(). Car va Bike undan meros oladi.

Backend misoli

BaseModel umumiy ID/sana beradi; User, Product undan foydalanadi.

Foydasi: DRY — bir xil kodni qayta yozmaslik, umumiy qoidani bitta joyda saqlash va classlarni mantiqiy bog‘lash.

2. Asosiy sintaksis

class Parent:
    def parent_method(self):
        return "Parent method"

class Child(Parent):
    pass

child = Child()
print(child.parent_method())  # Parent method

class Child(Parent): qismida child class qaysi classdan meros olayotgani ko‘rsatiladi. Child() objectida parent methodi ham mavjud bo‘ladi.

3. Parent attribute va methodlardan foydalanish

class Animal:
    def __init__(self, name):
        self.name = name

    def eat(self):
        return f"{self.name} ovqatlanyapti"

class Cat(Animal):
    def meow(self):
        return f"{self.name}: Miyov!"

cat = Cat("Momiq")
print(cat.eat())   # Momiq ovqatlanyapti
print(cat.meow())  # Momiq: Miyov!

Cat ichida __init__ yozilmagan bo‘lsa ham, u Animal.__init__ metodini meros oldi.

4. super() nima?

Child class o‘z __init__ metodini yozsa, parent constructorini super().__init__(...) orqali chaqirish kerak. Aks holda parent attributelari yaratilmaydi.

class User:
    def __init__(self, username, email):
        self.username = username
        self.email = email

class Admin(User):
    def __init__(self, username, email, permissions):
        super().__init__(username, email)
        self.permissions = permissions

admin = Admin("ali_admin", "ali@mail.com", ["read", "delete"] )
print(admin.username)    # ali_admin
print(admin.permissions) # ['read', 'delete']
KodNatija
super().__init__(username, email)Parent classdagi username va emailni yaratadi.
self.permissions = permissionsAdmin’ga xos yangi attribute qo‘shadi.
Xato: super() yozilmasa, admin.username mavjud bo‘lmasligi mumkin.

5. Method overriding

Child class parentdagi method bilan bir xil nomli method yozsa, child versiyasi ishlaydi. Bu overriding deyiladi.

class Notification:
    def send(self, message):
        return f"Xabar yuborildi: {message}"

class EmailNotification(Notification):
    def send(self, message):
        return f"Email yuborildi: {message}"

class SMSNotification(Notification):
    def send(self, message):
        return f"SMS yuborildi: {message}"

print(EmailNotification().send("Salom"))  # Email yuborildi: Salom
print(SMSNotification().send("Salom"))    # SMS yuborildi: Salom

Bu OOPning keyingi tamoyili — polymorphism — uchun ham asos yaratadi.

6. Parent methodni saqlab kengaytirish

class Product:
    def get_info(self):
        return "Mahsulot ma’lumoti"

class DigitalProduct(Product):
    def get_info(self):
        base_info = super().get_info()
        return base_info + "; yuklab olish mumkin"

book = DigitalProduct()
print(book.get_info())
# Mahsulot ma’lumoti; yuklab olish mumkin

super().get_info() parentdagi eski mantiqni saqlab, unga qo‘shimcha qo‘shadi.

class CanLogin:
    def login(self):
        return "Login qilindi"

class CanExport:
    def export(self):
        return "Hisobot export qilindi"

class Admin(CanLogin, CanExport):
    pass

admin = Admin()
print(admin.login())
print(admin.export())
Multiple inheritance: kichik mixin classlar uchun foydali, lekin murakkab hierarchy va bir xil method nomlari kodni chalkashtirishi mumkin.

8. isinstance() va issubclass()

class User: pass
class Admin(User): pass

admin = Admin()
print(isinstance(admin, Admin))  # True
print(isinstance(admin, User))   # True
print(issubclass(Admin, User))   # True

Admin object User ham hisoblanadi, chunki Admin Userdan meros olgan.

9. Backend amaliy loyiha: user rollari

class User:
    def __init__(self, username, email):
        self.username = username
        self.email = email

    def get_role(self):
        return "user"

class Admin(User):
    def __init__(self, username, email, permissions=None):
        super().__init__(username, email)
        self.permissions = permissions or []

    def get_role(self):
        return "admin"

    def can(self, permission):
        return permission in self.permissions

admin = Admin("ali", "ali@mail.com", ["users:read", "users:delete"] )
print(admin.get_role())              # admin
print(admin.can("users:delete"))    # True
Mustaqil mashq: Employee parent class yarating. Undan Developer va Designer classlarini meros oling. Parentda name/salary, childlarda language yoki tool attribute bo‘lsin.

10. Qachon inheritance ishlatish kerak?

IshlatingIshlatmang
Child haqiqatan parentning maxsus turi bo‘lsa: Admin — User.Faqat kodni qayta ishlatish uchun majburan “is-a” aloqa yasamang.
Umumiy interface/mantiq mavjud bo‘lsa.Objectlar “has-a” aloqada bo‘lsa, composition yaxshiroq: Order has Payment.
Parentdagi behavior childga mos bo‘lsa.Hierarchy juda chuqur va murakkab bo‘lsa.
