1. Tuple nima?

Tuple — bir nechta qiymatni saqlaydigan tartibli ma’lumot tuzilmasi. Listga o‘xshaydi, lekin tuple o‘zgarmas (immutable): yaratilgandan keyin elementini almashtirib, qo‘shib yoki o‘chirib bo‘lmaydi.

tuple_nomi = (qiymat1, qiymat2, qiymat3)
koordinata = (41.3111, 69.2797)
ranglar = ("qizil", "ko‘k", "yashil")
print(type(koordinata))  # <class 'tuple'>

3. Tuple: index, slicing va metodlar

Tuple tartibli bo‘lgani uchun list kabi index va slicing bilan ishlaydi.

fanlar = ("Python", "Django", "FastAPI", "PostgreSQL")
print(fanlar[0])    # Python
print(fanlar[-1])   # PostgreSQL
print(fanlar[1:3])  # ('Django', 'FastAPI')
print(len(fanlar))  # 4

Tupleda faqat ikkita asosiy metod bor:

MetodVazifasiMisol / natija
count(x)x necha marta qatnashganini sanaydi(1,2,1).count(1) → 2
index(x)x ning birinchi indexini qaytaradi("a","b").index("b") → 1
Xato: fanlar.append("Flask") va fanlar[0] = "Java" xato beradi. Tuple o‘zgarmas. Kerak bo‘lsa yangi tuple yarating: fanlar = fanlar + ("Flask",).

4. Tuple unpacking (ajratib olish)

Tuple ichidagi qiymatlarni bir qatorda o‘zgaruvchilarga joylash unpacking deyiladi.

foydalanuvchi = ("Ali", 21, "Toshkent")
ism, yosh, shahar = foydalanuvchi

print(ism)     # Ali
print(yosh)    # 21
print(shahar)  # Toshkent

O‘zgaruvchilar soni tuple elementlari soniga teng bo‘lishi kerak. Ortiqcha qiymatlarni * bilan olish mumkin:

mahsulot = ("Laptop", 850, "Dell", "16GB", "Qora")
nom, narx, *qolganlari = mahsulot
print(nom)        # Laptop
print(qolganlari) # ['Dell', '16GB', 'Qora']

Funksiyadan bir nechta qiymat qaytarish

    return "Lola", 20

6. Set nima?

Set — faqat noyob (takrorlanmaydigan) qiymatlarni saqlaydigan tartibsiz ma’lumot tuzilmasi. U { } bilan yaratiladi.

Tartibsiz: set ekranga elementlarni boshqa tartibda chiqarishi mumkin. Shuning uchun setda index yo‘q: sonlar[0] — xato.

9. Set operatorlari va metodlari

Setlar matematik to‘plamlar kabi ishlaydi.

a = {1, 2, 3, 4}

AmalOperator / metodNatija

Kesishmaa & b yoki a.intersection(b){3, 4}
Farqa - b yoki a.difference(b){1, 2}
Simmetrik farqa ^ b yoki a.symmetric_difference(b){1, 2, 5, 6}
Qism to‘plama.issubset(b)True/False
Ust to‘plama.issuperset(b)True/False
Umumiy element yo‘qmi?a.isdisjoint(b)True/False
admin_permissions = {"read", "write", "delete"}

print(admin_permissions & user_permissions) # {'read'}
print(admin_permissions - user_permissions) # {'write', 'delete'}
print("delete" in admin_permissions)      # True

Set comprehension

List comprehension kabi, set comprehension ham mavjud. Natija doim noyob qiymatlar bo‘ladi.

sonlar = [1, 2, 2, 3, 4, 4, 5]
kvadratlar = {son ** 2 for son in sonlar if son % 2 == 0}
print(kvadratlar)  # {4, 16}

Dictionary bilan

user = {"id": 1, "name": "Ali", "role": "admin"}
keys = set(user.keys())
print(keys)  # {'id', 'name', 'role'}
