4. Bir nechta parametr

def user_info(ism, yosh, shahar):
    print(f"Ism: {ism}")
    print(f"Yosh: {yosh}")
    print(f"Shahar: {shahar}")

user_info("Aziza", 20, "Samarqand")

Argumentlar odatda tartib bo‘yicha parametrga tushadi:

# ism = Ali, yosh = 22, shahar = Toshkent
user_info("Ali", 22, "Toshkent")

Keyword argument

Argument nomini aniq yozish mumkin. Bu holda tartib muhim emas:

user_info(shahar="Buxoro", ism="Umar", yosh=19)
Qoida: positional argument (oddiy argument) keyword argumentdan oldin yoziladi. user_info("Ali", yosh=21, "Toshkent") — xato.

5. return nima?

return funksiya natijasini tashqariga qaytaradi. print() faqat ekranga chiqaradi; return esa qiymatni keyingi hisoblashda ishlatishga beradi.

print()

Natijani ko‘rsatadi. Qiymat qaytarmaydi (None qaytaradi).

return

Natijani qaytaradi. Uni o‘zgaruvchiga saqlash yoki boshqa funksiyaga uzatish mumkin.

def qoshish(a, b):
    return a + b

natija = qoshish(5, 3)
print(natija)  # 8
print(qoshish(10, 7))  # 17
def qoshish_print(a, b):
    print(a + b)

natija = qoshish_print(5, 3)
print(natija)  # avval 8, keyin None
Ko‘p uchraydigan xato: hisoblangan qiymatni boshqa joyda ishlatish kerak bo‘lsa print() emas, return yozing.

7. Default parametrlar

Default parametr — argument berilmasa ishlatiladigan standart qiymat.

def salom_ber(ism, til="uz"):
    if til == "uz":
        return f"Salom, {ism}!"
    elif til == "en":
        return f"Hello, {ism}!"
    return f"Noma’lum til: {til}"

print(salom_ber("Ali"))        # Salom, Ali!
print(salom_ber("Lola", "en")) # Hello, Lola!
Tartib qoidasi: default parametrlar default bo‘lmagan parametrlardan keyin yoziladi. def f(a=1, b): — xato; def f(a, b=1): — to‘g‘ri.

O‘zgaruvchan default qiymat muammosi

# Noto‘g‘ri usul
def add_skill(skill, skills=[]):
    skills.append(skill)
    return skills

Bu list bir necha chaqiruvda saqlanib qolishi mumkin. To‘g‘ri usul:

def add_skill(skill, skills=None):
    if skills is None:
        skills = []
    skills.append(skill)
    return skills

8. *args — istalgan miqdordagi argument

*args funksiyaga berilgan ortiqcha positional argumentlarni tuple qilib qabul qiladi. Nomi aynan args bo‘lishi shart emas; * belgisi muhim.

def jami_hisobla(*sonlar):
    return sum(sonlar)

print(jami_hisobla(1, 2, 3))       # 6
print(jami_hisobla(10, 20, 30, 40)) # 100
def teglarni_chiqar(*teglar):
    for teg in teglar:
        print(f"#{teg}")

teglarni_chiqar("python", "backend", "django")

Funksiya ichida teglar tipi tuple bo‘ladi.

9. **kwargs — nomlangan argumentlar

**kwargs istalgan miqdordagi keyword argumentlarni dictionary qilib qabul qiladi. Nomi o‘zgarishi mumkin, ** belgisi muhim.

def user_yarat(**malumotlar):
    for key, value in malumotlar.items():
        print(f"{key}: {value}")

user_yarat(name="Ali", age=21, role="admin")

11. Scope: local va global o‘zgaruvchi

Scope — o‘zgaruvchi qayerdan ko‘rinishini bildiradi. Funksiya ichida yaratilgan o‘zgaruvchi local, tashqaridagi o‘zgaruvchi esa global hisoblanadi.

sayt_nomi = "My API"  # global

def ko‘rsat():
    xabar = "Xush kelibsiz"  # local
    print(sayt_nomi)
    print(xabar)

ko‘rsat()
# print(xabar) — xato, chunki xabar funksiyadan tashqarida ko‘rinmaydi
Backend tavsiyasi: global qiymatni funksiya ichida o‘zgartirishdan qoching. Kerakli qiymatni parametr orqali bering va natijani return qiling.

13. Lambda — kichik bir qatorli funksiya

lambda sodda, qisqa funksiyani bir qatorda yozishga xizmat qiladi. Murakkab mantiq uchun oddiy def ishlating.

print(kvadrat(5))  # 25

users = [{"name": "Ali", "age": 21}, {"name": "Lola", "age": 19}]
users.sort(key=lambda user: user["age"])

14. Backend amaliy loyiha: foydalanuvchi validatsiyasi

def validate_user(data: dict) -> dict:
    """Foydalanuvchi ma’lumotini tekshiradi."""
    required_fields = ("username", "email", "password")

    for field in required_fields:
        if not data.get(field):
            return {"success": False, "message": f"{field} majburiy"}

    if len(data["password"]) < 8:
        return {"success": False, "message": "Parol kamida 8 belgi bo‘lsin"}

    return {
        "success": True,
        "message": "Foydalanuvchi ma’lumoti to‘g‘ri",
        "user": {"username": data["username"], "email": data["email"]}
    }

new_user = {"username": "ali_dev", "email": "ali@mail.com", "password": "python123"}
print(validate_user(new_user))
